3. # **세계관**

   1. ## **개요**

      1. 길드 레이스는 A사의 자본으로 국가급 산업이 되었고, 최종 보스에 "인생을 바꿀 무언가"가 있다는 사실이 퍼지며 대 길드 시대가 열렸다.

   2. ## **설정**

      1. 길드 레이스는 원래 길드가 관리하는 보스 기체를 누가 더 많이, 더 높은 난이도로 쓰러뜨리는지 겨루던 소규모 놀이였다. A총수가 기업 차원에서 길드 레이서를 전폭 지원하면서 막대한 자본이 유입되었고, 길드 레이스는 국가 단위 산업으로 성장했다.

      2. 실력만 있으면 큰돈을 버는 구조가 되자 **길드 레이서라는 직업**과 **랭커라는 개념**이 생겨났다. A사의 갑작스러운 투자에 의문을 품은 자들이 조사한 끝에, 아직 아무도 도달하지 못한 최종 보스에 인생을 바꿀 무언가가 있다는 사실이 퍼졌다.

   3. ## **산업 구조**

      1. 길드  
         1. 레이스 주최, 보스 기체 관리, 랭킹 공인, 포상금 지급  
      2. 로봇 격투 산업  
         1. 지역별 경기장을 중심, 대중은 스포츠,관중,베팅,스폰서십등이 얽혀있다.  
      3. 부품 제조 공장  
         1. 대부분의 기업들이 자사 코어에 자사 부품만 호환이되게 설계를 하여 종속시킨다.  
      4. 지역 경제  
         1. 각 지역마다 선호 부품과 고철의 종류 경기 판돈이 기준가가 다르다.  
      5. 고철 / 폐기물  
         1. 대기업 폐부품으로 고물상을 통해 하위계층에게 순환되는 구조이다.

   4. ## **연표**

| 항목 | 내용 |
| :---- | :---- |
| 위상 | 세계 최고의 로봇 기술력을 보유한 거대 기업 (현실 기준 마이크로소프트, 삼성, 엔비디아, 애플 느낌) |
| 사업 구조 | 자체 코어, 전용 부품 기반 운영, 타사 부품과 호환 차단 (기술적 호환성 문제도 존재) |
| 총수 | 막대한 자본과 권력, 코어 v.1 보유 |
| 시장 내 역할 | 상위 랭커를 후원 대상으로 삼아 직접·간접 영향력 행사. 레이스마다 1위를 지키는 후원 랭커 보유 |

   5. ## **A사 (이름 못정함)**

      1. 위상   
         1. 세계 최고의 로봇 기술력을 보유한 거대기업 (현실기준 : 마이크로소프트,삼성,엔비디아,애플 느낌)  
      2. 사업구조  
         1. 자체 코어  
         2. 전용 부품 기반 운영  
         3. 타사 부품과 호환 차단  
            1. 기술적인 문제(타사 코어랑 부품 호환성)도 존재  
      3. 총수   
         1. 막대한 자본, 권력을 가진 인물  
         2. 현재 세계 최고의 로봇 기술을 보유  
      4. 시장 내 역할  
         1. 지역 랭커들을 후원의 대상으로 여기고 직접 혹은 간접적으로 영향력을 행사  
         2. 스토리상 우스갯 소리로 “랭커가 되려면 A사에 인연이 있어야 된다”라는 말이 들릴정도로 많은 지역 랭커들이 A사 후원을 받음

4. # **전체적인 시놉시스(임시)**

   1. ## **프롤로그 – 마지막 설계**

      1. A총수에게 진 빚으로 코어 v.1을 완성한 아버지는 기술 유출을 우려한 A총수에게 살해당한다. 죽기 직전 그는 설계도를 지우고 A총수에게 말한다. "코어의 결함을 메울 장치는 길드 레이스 최종 보스 안에 있다. 넌 절대 손에 넣지 못할 거다."

   2. ## **1막 – 대 길드 시대**

      1. 10년 뒤. 장치를 노린 A사의 투자로 길드 레이스는 국가 산업이 되었다. 성인이 된 주인공은 유언 집행으로 고물상 지하의 홍채 인식 작업실을 발견한다. 그곳에는 코어 v.2 설계도와 아버지의 메모가 있다. 재료비가 부족했지만, 코어만 완성하면 어떤 잡동사니 부품이든 연결할 수 있다는 사실을 깨닫는다. 최종 보스 속 장치가 아버지의 유산이라고 확신한 주인공은 전 재산으로 코어를 완성하고 가명으로 길드에 등록한다.

   3. ## **2막 – 무명의 고철 랭커**

      1. 고물상 폐부품으로 조립한 기체로 보스를 토벌하며 랭킹을 끌어올린다. 서로 다른 회사의 부품을 섞어 쓰는 무명 신인이 100위권에 들어오자 A사 에이전트의 보고가 올라간다.

   4. ## **3막 – 추적**

      1. 범용 코어의 존재를 확신한 A총수가 A사 후원 랭커를 레이스 1위 경쟁에 투입하고, 경매장과 길드 안팎에서 주인공을 압박한다. 주인공의 정체가 드러난다.

   5. ## **4막 – 최종 레이스**

      1. 최종 레이스에서 아무도 도달하지 못한 최종 보스를 쓰러뜨리고 장치를 손에 넣어 코어 v.2를 완성한다. A총수의 코어 v.1과 1:1로 맞서 이를 부수고, 아버지 죽음의 진실을 세상에 알린다

      1. 개념	  
         1. 고물상 혹은 경매장에서 사온 부품들을 가지고 크래프팅을 진행한다.  
         2. 제작대를 이용하여 조합법을 통해 로봇의 파츠를 제작을 할수있다.  
         3. 총 5개의 외부 파츠 머리, 왼팔, 오른팔, 왼다리, 오른다리와 1개의 내부 코어로 구성  
      2. 파츠  
         1. 고물상이나 경매장에서 얻은 부품을 제작대에서 조합해 파츠를 만든다. 

         2. 로봇은 외부 파츠 5개(머리, 왼팔, 오른팔, 왼다리, 오른다리)와 내부 코어 1개로 구성된다. 

         3. 각 파츠는 고유 속성과 스탯, 그리고 전투 스킬 1개를 제공한다.

         5. 부품 조합의 의미: 빌드 다양성, 전투 스타일 분화, 경제적 판단, 리스크 관리

   7. ## **부품 내구도 / 파괴 시스템**

      1. 내구도 개념  
         1. 각 파츠에 내구도가 존재하며, 보스의 부위 타격 스킬에 맞을 때만 감소한다  
         2. 내구도가 0이 된 파츠에 한해 패배 시 등급별 확률로 파괴 판정을 한다. 확률은 등급이 높을수록 낮다

| 결과 | 획득 / 처리 |
| :---- | :---- |
| 승리 | 골드, 코어 EXP, 랭킹 점수 획득. 내구도 0인 파츠는 1로 응급 복구 |

          1. 1\~100위는 이름과 성장 곡선을 가진 네임드 랭커 5명이 채우고, 6\~100위 필러는 저장하지 않고 계산식으로만 존재한다.

          2. 네임드 랭커 성장 곡선(점수는 절대 감소하지 않음, 노이즈 ±3%)

             1. Score\_i(d) \= T\_i \\cdot f\\left(\\frac{d}{90}\\right) \\cdot (1 \\pm 0.03)

| 유형 | f(x) | 보드에서 보이는 모습 |
| :---- | :---- | :---- |
| 꾸준형 | x | 일정하게 오름 |
| 초반 질주형 | 1 − (1 − x)² | 시즌 초 상위권, 후반 정체 |
| 막판 스퍼트형 | x² | 시즌 말 급등 |
| 계단형 | 주 단위 상승 | 주말마다 한 번에 오름 |

          3. 슬롯별 목표 점수 (레이스 1 기준)

             1. T(k) \= T\_1 \\cdot k^{-0.32}

| 순위 슬롯 | 목표 점수 | 근거 |
| :---- | :---- | :---- |
| 1위 | 9,100 | 어려움과 헬을 절반씩 섞은 수준 |
| 10위 | 약 4,770 |  |
| 30위 | 약 3,505 |  |
| 100위 | 약 2,500 | 매주 보통 3회 완주(약 3,100점)보다 약간 낮게 |

          4. 필러 랭커 (100위 안에 절대 영향없음)

             1. S(r, d) \= C(d) \\cdot \\left(\\frac{100}{r}\\right)^{0.6}  
             2. C(d) \= 그날 100위 네임드의 점수.   
             3. r ≥ 101이면 항상 S \< C(d)이므로 필러가 100위 안으로 들어오지 않는다  
             4. 플레이어 점수 P \< C(d)일 때 순위 \= 100 × (C(d) / P)^(1/0.6),   
             5. P ≥ C(d)이면 네임드 5명과 직접 비교  
             6. 시드 \= 세이브 시드 \+ 시즌 번호 \+ 일차

    13. ## **데미지 플로팅 텍스트 & 치명타 강조 연출시스템**

        1. 개요  
           1. 피격시 대상 머리위 데미지 숫자를 띄우고 치명타는 크기·색·움직임을 키워 구분, “내가 얼마나 쎄게 떄렸는지” 직접적으로 체험되게 하는 목적  
           2. 래퍼런스   
              1. 메이플 스토리  
           3. 적용범위  
              1. 플레이어 ↔ 보스↔ 파츠 내구도  
           4. 제외 범위  
              1. 데미지 계산식 자체  
              2. 사운드 에셋  
        2. 데미지 타입 분류

| 우선순위 | 타입 | 발생 조건 |
| ----- | ----- | ----- |
| 1 | 치명타 (Critical) | 전투 로직이 isCritical \= true 반환 |
| 2 | 기믹·약점 히트 | 보스 부위 파괴, 돌진 전 누적 피해 등 기믹 판정 히트 |
| 3 | 파츠 스킬 (Q/W/E/R) | 파츠 스킬로 준 피해 |
| 4 | 일반 타격 (D) | 기본기 콤보 피해 |
| 5 | 플레이어 피격 | 보스·적에게 맞음 |
| 6 | 회복 | HP 회복 |
| 7 | MISS / 무효 | 회피(Space) 성공, 무적 구간 피격 |

        3. 연출 상세 사양  
           1. 폰트가 아닌 숫자 스프라이트 시트로 제작한다.  
              1. 데미지 스킨 교체 가능  
              2. 글자 렌더링 비용 감소  
           2. 자간은 \-6px 기준 덩어리 처럼 읽히게  
           3. 치명타는 ±3° 랜덤 회전을 주어 거친느낌으로  
           4. 큰수는 축약하지 않고 전체 표시  
           5. 5자리 이상 나오면 밸런스후 단위표기를 재검토  
        4. 애니메이션 타임 라인

| 구간 | 일반 히트 | 치명타 |
| ----- | ----- | ----- |
| 등장 | 0\~0.08초: 스케일 0.6 → 1.0, 알파 0 → 1 | 0\~0.06초: 스케일 0.4 → 1.8 (오버슈트) |
| 안착 | 없음 | 0.06\~0.16초: 스케일 1.8 → 1.6, 백색 플래시 1프레임 |
| 상승 | 0.08\~0.55초: 위로 40px, EaseOutCubic | 0.16\~0.8초: 위로 55px, EaseOutCubic \+ 미세 흔들림 ±2px |
| 소멸 | 0.55\~0.8초: 알파 1 → 0 | 0.8\~1.1초: 알파 1 → 0, 스케일 1.6 → 1.3 |

        5. 치명타 추가 강조 연출  
           1. "CRITICAL" 라벨: 숫자 왼쪽 위에 작게, 숫자보다 0.03초 먼저 등장해 시선을 끌어오는 역할  
           2. 임팩트 파티클: 숫자 뒤에 방사형 스파크 6\~8개, 0.2초  
           3. 히트스톱: 공격자·피격자 애니메이션만 0.04초 정지 (전체 게임 시간 정지 아님)  
           4. 카메라 쉐이크: 진폭 4px, 0.1초. 파츠 스킬 치명타는 6px  
           5. 사운드: 일반 타격음 위에 금속성 "챙" 레이어 추가  
        6. 배치 겹침 처리 규칙  
           1. 같은 대상에게 0.15초 안에 들어온 히트는 한묶음  
           2. 위로 쌓는다  
           3. 히트가 몰려도 숫자가 겹치지 않게  
              1. 기준점: 피격 대상의 머리 위 소켓(HeadAnchor) \+ Y 20px. 보스처럼 큰 오브젝트는 피격 지점(히트 포인트) 기준으로 띄울지 옵션을 둔다.  
              2. 스택 간격: 숫자 높이 × 0.85 만큼 위로 쌓음. 치명타 줄은 자기 크기만큼 간격을 더 차지한다.  
              3. 수평 흔들림: 각 줄에 X ±8px 랜덤 오프셋. 단, 스택 안에서는 줄마다 방향을 번갈아 두어 한쪽으로 쏠리지 않게 한다.  
              4. 최대 줄 수: 대상 1명당 동시 8줄. 초과 시 가장 오래된 일반 히트부터 즉시 페이드아웃(0.1초). 치명타는 마지막까지 보호한다.  
              5. 화면 밖 처리: 기준점이 화면 밖이면 가장자리 안쪽 24px로 클램프. 천장까지 튀어오르는 바퀴형 보스에서 숫자가 잘리지 않게 하기 위함이다.  
              6. 월드 고정 vs 따라가기: 띄운 순간의 월드 좌표에 고정한다. 돌진하는 보스를 따라가면 숫자가 끌려가 읽기 어렵다.  
        7. 데이터 테이블 및 시스템 설계

        8. 예외처리  
           1. 색각 보조: 빨강·초록 대비에만 기대지 않도록 치명타는 항상 크기·라벨·모양으로도 구분한다. 보조 모드에서는 외곽선을 3px로 키우고 회복을 하늘색 계열로 바꾼다.

| 상태 | 사용 키 | 비고 |
| ----- | ----- | ----- |

| 전투 | ←/→ 이동, ↑ 점프, Space 회피, D 기본기, Q/W/E/R 파츠 스킬 | 사이드뷰 |
| 대화 | Space / Enter / 좌클릭 확인, Esc 스킵, Ctrl(홀드) 빨리감기, Tab 오토, L 백로그 |  |

           1. 상태 분리  
              1. 세 상태는 동시에 켜지지 않는다 a. 대화 중 Space를 눌러도 회피가 나가지 않는다  
              2. 대화가 끝난 직후, 누르고 있던 키를 뗄 때까지 필드·전투 입력을 받지 않는다   
                 1. 마지막 대사를 넘긴 Space가 회피로 이어지는 것 방지  
           2. 시간처리  
              1. 대화창이 열리면 인게임 시간이 멈춘다 (6.a.v 예외처리와 동일 규칙)

              2. 보스 진입 대화 중에는 보스와 투사체도 멈춘다  
              3. 전투 바크, 관중 말풍선은 시간을 멈추지 않는다  
           3. 진행 기록과 세이브  
              1. 저장 항목   
                 1. 대사별 재생 횟수   
                 2. 읽은 대사 줄 (빨리감기·스킵 판단용)   
                 3. 스토리 챕터 등 대사 전용 값  
              2. 대사는 순서 번호가 아닌 고유 ID로 기록한다   
                 1. 중간에 대사를 추가·삭제해도 기존 세이브의 기록이 어긋나지 않는다  
              3. 대사 ID를 바꿀 때는 이전 ID를 함께 적어 기록을 이어받는다
