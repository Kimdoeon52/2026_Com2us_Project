# [Git Commit Guidelines (AGENTS.md / GEMINI.md)]
# 1. 모든 Git 커밋 메시지는 반드시 한국어(한글)로 작성함.
# 2. 제목 형식: [타입] 한글 요약
#    - feat     : 새로운 기능 추가
#    - fix      : 버그 수정
#    - refactor : 코드 리팩토링
#    - docs     : 문서 수정 (설계서, 가이드 등)
#    - chore    : 빌드, 설정, 패키지, 단순 작업
#    - test     : 테스트 코드 추가/수정
#    - style    : 코드 서식, 세미콜론 등 (동작 변경 없음)
# 3. 본문은 글머리 기호(-)로 핵심만 한글로 간결하게 작성함.
# 4. 고유명사/클래스명을 제외한 모든 서술을 한글로 작성함.
