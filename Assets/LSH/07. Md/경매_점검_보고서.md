## 1. 랭킹 2등 "강퇴" 스킬 점검 (BossNpc2)

### 1-1. 대상과 동작
- 스크립트: `02. Scripts/AI/MainCharacter/Stage1/BossNpc2.cs`
- 프리팹: `05. Prefab/Stage1/Boss2.prefab` (데이터: `04. SO/Gold/Boss/Stage1/Rank2.asset`, 이름 "랭크2등")
- 대사: "흐응~ 넌 강퇴야~"
- 효과: 참가자 중 한 명을 강제로 포기(`IsGiveUp = true`)시킴
- 발동: 보스가 입찰하려 할 때 10% 확률, 라운드당 1회 (`SetSkillChance(10, 1)`)

### 1-2. 정상 확인된 부분
| 항목 | 결과 |
|---|---|
| Boss2 프리팹 → `BossNpc2` 스크립트 연결 | 정상 |
| 프리팹의 데이터 → Rank2 에셋 연결 | 정상 |
| Stage1 보스 명단(`AuctionStageData`)에 포함 | 정상 (두 번째 항목) |
| 강퇴된 AI 연출 | 반투명(0.1) 처리 + 포기 대사 말풍선 |
| 강퇴 후 입찰 | `NpcAiBase`/`BossAiBase`/`Npc4`/`Npc5`의 `RaiseThink`가 `IsGiveUp`을 검사하므로, 고민 중 강퇴돼도 뒤늦게 입찰하지 않음 |

### 1-3. 제대로 동작하지 않는 경우
| # | 문제 | 원인 | 영향 |
|---|---|---|---|
| 1 | 스킬이 헛방 날 수 있음 | 타겟을 무작위로 뽑고, 자기 자신이면 그냥 `return`. 이미 포기한 대상도 걸러내지 않음 | 스킬 횟수는 이미 차감되고 컷씬도 재생되지만 아무도 강퇴되지 않음. 참가자 5~7명 기준 자기 자신이 뽑힐 확률만 약 15~20% |
| 2 | 플레이어는 강퇴 대상이 아님 | 대상 목록이 `auctionAiList`뿐이고 플레이어가 없음 | "다른 한 명"에 플레이어를 포함하는 기획인지 확인 필요 |
| 3 | 최고 입찰자를 강퇴하면 그대로 낙찰됨 | `UseBigSkill`이 `IsGiveUp`만 바꾸고 `WinnerID`는 건드리지 않음 | 강퇴당한 사람이 현재가에 낙찰됨 |

### 1-4. 참고 사항
- 강퇴가 일어났다는 안내 메시지(채팅/콘솔)는 없음. 강퇴된 AI의 말풍선만 나옴.
- 강퇴가 컷씬 재생보다 먼저 일어나서, 배너가 뜨기 전에 대상이 먼저 반투명해짐.
- 주먹 경매에서는 보스 스킬이 쓰이지 않음 (일반 경매 전용).
- 비슷한 문제: 플레이어가 최고 입찰자인 상태에서 포기하고 이후 아무도 입찰하지 않으면, `IfPlayerWin`이 그대로라 포기했는데도 플레이어가 낙찰됨.

### 1-5. 결정이 필요한 사항
1. 스킬이 헛방 나지 않게 (자신/이미 포기한 대상 제외하고 다시 뽑기) 고칠지
2. 플레이어도 강퇴 대상에 넣을지
3. 최고 입찰자가 강퇴되면 낙찰권을 어떻게 처리할지 (유지 / 박탈 후 직전 입찰자에게 / 유찰)

## 2. 첫 화면에 뒷 canvas가 보이는 문제

### 2-1. 결론
**원인을 확정하지 못함.** 이 체크아웃의 `01. SCENE/Auction.unity`에는 Canvas가 하나뿐이고, 현재 코드가 참조하는 모드 선택 패널·상점·AI 슬롯 등이 없음. 사용 중인 씬과 다른 상태일 수 있어 씬 파일로는 단정할 수 없음.

### 2-2. 코드상 후보
| # | 후보 | 근거 |
|---|---|---|
| A | 타이머 바가 처음부터 켜져 있음 | `Auction.Awake()`에서 레이즈/포기 버튼, 주먹 UI, 모드 패널, 상점은 끄지만 `timeBar`는 끄지 않음. 첫 경매의 타이머가 끝나야 꺼짐 |
| B | 모드 선택 중 메인 UI가 그대로 보임 | `NPCImageOff()`는 NPC 이미지만 끔. 채팅·가격·골드·콘솔·배경은 켜진 채로 모드 선택 패널이 그 위에 뜸 |
| C | 다른 씬에서 넘어온 Canvas | `CoreSystem_UI`, `LoadingManager`(LJS)가 `DontDestroyOnLoad`라서 해당 canvas가 남아 있을 수 있음 |

### 2-3. 확인 방법
1. Play 중 보이는 canvas의 이름을 Hierarchy에서 확인
2. `DontDestroyOnLoad` 항목 아래에 Canvas가 있으면 후보 C
3. 씬 안의 Canvas라면 후보 A 또는 B (`timeBar`와 메인 UI의 초기 활성 상태 확인)
4. 보이는 canvas의 이름이나 스크린샷을 알려주면 원인을 좁힐 수 있음

### 2-4. 고친다면
- A: `Awake()`에서 `timeBar`도 비활성화
- B: 모드 선택 중에는 메인 UI(채팅·가격·콘솔 등)를 숨기거나, 모드 패널을 불투명 배경으로 덮기
- C: 해당 canvas를 경매 씬에서는 끄거나 `Sort Order`를 조정
