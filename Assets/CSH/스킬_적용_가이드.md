## 1. 먼저 알아둘 것 (3분)

### 1-1. 시간은 전부 "프레임"으로 적는다

전투는 1초에 60번 돌아갑니다. 인스펙터의 숫자 칸은 전부 **프레임 수**입니다.

| 초 | 프레임 | | 초 | 프레임 |
|---|---|---|---|---|
| 0.1초 | 6 | | 1초 | 60 |
| 0.15초 | 9 | | 1.5초 | 90 |
| 0.3초 | 18 | | 2.5초 | 150 |
| 0.5초 | 30 | | 4초 | 240 |

**계산법: 초 × 60 = 프레임**

### 1-2. 행동 하나는 세 구간으로 나뉜다

```
[ 선딜 Startup ] → [ 활성 Active ] → [ 후딜 Recovery ]
   준비 동작          공격 판정이 켜짐      손 거두는 동작
   (판정 없음)                             (이 동안 다른 입력 무시)
```

홀드형 스킬은 맨 앞에 **차지(Charge)** 구간이 하나 더 붙습니다. 키를 누르고 있는 동안 계속 이 구간에 머뭅니다.

### 1-3. 등장인물은 딱 세 개

| 이름 | 하는 일 | 어디 있나 |
|---|---|---|
| **스킬 에셋** | 스킬 하나의 수치(프레임, 피해, 쿨타임...) | Project 창에서 직접 만드는 `.asset` 파일 |
| **PlayerSkillLoadout** | "Q에는 이 스킬, W에는 저 스킬" 연결표 | 플레이어 오브젝트에 붙는 컴포넌트 |
| **PlayerSkillInputSource** | 키보드를 읽음 | 플레이어 오브젝트에 붙는 컴포넌트 |

스킬을 바꾸고 싶으면 **에셋을 만들고 → Loadout 칸에 끌어다 놓으면** 끝입니다.

## 2. 씬 준비 (처음 한 번만)

이미 해둔 씬이면 건너뛰세요.

> 2026-10-26 기준 아래 4개 씬은 아직 **예전 방식**입니다:
> `KKH/01.Scene/Battle`, `KKH/01.Scene/Battle_Test_KKH`, `NYH/01. SCENE/Battle`, `Scenes/Copys_1020/Battle`
> 다른 사람 폴더의 씬은 수정 전에 그 사람에게 먼저 말해주세요 (씬 파일은 머지 충돌이 잘 납니다).

1. Hierarchy에서 **플레이어 오브젝트**를 선택합니다.
   (`ActionExecutor`, `PlayerRobotBootstrap`이 붙어 있는 오브젝트)
2. Inspector에서 **`Player Input Source` 컴포넌트를 제거**합니다. (⋮ → Remove Component)
   - 남겨두면 예전 방식과 새 방식 중 어느 쪽이 잡힐지 모릅니다. 꼭 지우세요.
3. **Add Component → `Player Skill Input Source`** 추가.
   - 키 설정은 기본값(D / Q / W / E / R / Space) 그대로 두면 됩니다.
4. **Add Component → `Player Skill Loadout`** 추가.
5. Loadout의 칸을 채웁니다.

| 칸 | 키 | 넣을 것 |
|---|---|---|
| Basic | D | 기존 기본공격 에셋 |
| Left Arm | Q | 왼팔 스킬 |
| Right Arm | W | 오른팔 스킬 |
| Left Leg | E | 왼다리 스킬 |
| Right Leg | R | 오른다리 스킬 |
| Dodge | Space | 기존 회피 에셋 |

> 지운 `Player Input Source`에 꽂혀 있던 에셋을 그대로 옮기면 됩니다.
> 예전의 "Q 강화판정 / W 강화판정" 칸은 새 Loadout에 **없습니다**. 강화판정은 스킬 에셋 안에 넣습니다 (5장).

**3번과 4번은 반드시 2번과 같은 오브젝트에** 붙여야 합니다. 다른 오브젝트에 붙이면 인식이 안 됩니다.

## 3. 어떤 종류로 만들지 고르기

아래 질문에 차례로 답하세요.

```
키를 누르는 시간에 따라 뭔가 달라지나요?
│
├─ 아니오 ──────────────────────────────▶ 레시피 A (일반 Action Data)
│                                          예: D 기본기, 회피, 다리 스킬
│
└─ 예
    │
    누르고 있는 동안 캐릭터가 멈춰서 뭔가 하나요? (모으기, 연타)
    │
    ├─ 아니오 (짧게/길게만 구분) ──────▶ 레시피 B (Tap Skill)
    │                                      예: 부스터 샷, 지면 강타, 붐버
    │
    └─ 예 ─────────────────────────────▶ 레시피 C (Hold Skill)
                                           예: 차지 샷, 연속 펀치, 레이저 샷
```

| 종류 | 생성 메뉴 | 키 동작 | 누르는 동안 이동 |
|---|---|---|---|
| 일반 | `Create > NYH > Combat > Action Data` | 누르는 순간 나감 | - |
| 탭형 | `Create > CSH > Skill > Tap Skill (탭형 베이스)` | 뗄 때 짧게/길게 판단 | **가능** |
| 홀드형 | `Create > CSH > Skill > Hold Skill (홀드형 베이스)` | 누르는 순간 시작, 뗄 때 발동 | **불가** |

## 4. 레시피 A — 그냥 누르면 나가는 스킬

기존 방식 그대로입니다. 새로 배울 것이 없습니다.

1. Project 창 우클릭 → `Create > NYH > Combat > Action Data`
2. 파일 이름을 스킬 이름으로 바꿉니다 (예: `Leg_BoosterDash`)
3. 아래 [공통 칸](#공통-칸-모든-스킬-에셋에-있음)을 채웁니다
4. Loadout의 원하는 칸에 끌어다 놓습니다

### 공통 칸 (모든 스킬 에셋에 있음)

탭형·홀드형 에셋에도 이 칸들이 전부 똑같이 있습니다. 자주 쓰는 것만 추렸습니다.

| 칸 (Inspector 표시 이름) | 뜻 | 예시 |
|---|---|---|
| **Action Name** | 이름. 로그에 이대로 찍힘 | `부스터 샷` |
| **Source** | `Core Fixed` = 부위 파괴돼도 사용 가능 / `Part` = 부위 소속 | Q/W/E/R 스킬은 `Part` |
| **Required Part** | 이 부위가 파괴되면 사용 불가 | 왼팔 스킬 → `Left Arm` |
| **Startup Frames** | 선딜 | 0.15초 → `9` |
| **Active Frames** | 활성 (판정 켜지는 시간) | |
| **Recovery Frames** | 후딜 | 0.35초 → `21` |
| **Is Invincible During Active** | 활성 동안 무적 | 회피 |
| **Damage** | 피해량 | |
| **Hit Interval Frames** | 0 = 한 번만 맞힘 / 숫자 = 그 간격마다 다시 맞힘 (다단히트) | 0.1초마다 → `6` |
| **Animation Clip Name** | Animator 스테이트 이름 | |
| **Advance Distance** | 시전 중 앞으로 나가는 거리 | |
| **Ground Only** | 켜면 공중에서 못 씀 | 회피, 지면 강타 |
| **Projectile** | 투사체를 쏘는 스킬이면 넣음 | 붐버 |
| **Cooldown Frames** | 쿨타임 | 4초 → `240` |
| **Cooldown Owner** | 다른 에셋과 쿨타임을 공유할 때 그 에셋 (5장, 6장에서 사용) | |
| **Cylinder Cost** | 쓸 때 소모하는 탄 수 | 강화판정 → `1` |
| **Fallback Action** | 탄이 부족할 때 대신 나갈 에셋 | |
| **Frame Boxes** | 판정 박스 목록 | |

## 5. 레시피 B — 탭형 (짧게 / 길게)

기획서: **짧게 누름 = 일반, 0.3초 이상 누르고 뗌 = 강화(탄 1발 소모)**

에셋을 **2개** 만듭니다: 일반판정 1개 + 강화판정 1개.

### 단계

**① 일반판정 에셋 만들기**
- `Create > CSH > Skill > Tap Skill (탭형 베이스)` → 이름 예: `BoostShot`
- 공통 칸 채우기 (쿨타임 포함)

**② 강화판정 에셋 만들기**
- `Create > NYH > Combat > Action Data` → 이름 예: `BoostShot_Charged`
- 공통 칸 채우기, 그리고 아래 4칸은 **꼭** 이렇게:

| 칸 | 값 | 이유 |
|---|---|---|
| Cylinder Cost | `1` | 탄 1발 소모 |
| Fallback Action | ① 에셋 (`BoostShot`) | 탄이 없으면 일반판정으로 나감 |
| Cooldown Owner | ① 에셋 (`BoostShot`) | 일반/강화가 쿨타임 하나를 같이 씀 |
| Cooldown Frames | ①과 **같은 숫자** | 비워두면(0) 강화판정을 쓴 뒤 쿨타임이 안 돔 |

**③ 일반판정 에셋에 강화판정 연결**
- ① 에셋을 선택하고, 맨 아래 **"탭형"** 칸을 채웁니다:

| 칸 | 값 | 설명 |
|---|---|---|
| Charged Variant | ② 에셋 (`BoostShot_Charged`) | 길게 눌렀을 때 나갈 것 |
| Charge Threshold Frames | `18` | 이 프레임 이상 누르고 떼면 강화 (18 = 0.3초) |
| Auto Release Frames | `0` | 0이 아니면, 이만큼 누르고 있을 때 안 떼도 강화가 자동 발동 |

**④ Loadout의 Q(또는 W)에 ① 에셋을 넣습니다.** ②는 넣지 않습니다.

### 이렇게 동작합니다

```
Q 짧게 눌렀다 뗌     → BoostShot (일반)
Q 0.3초 이상 누르고 뗌 → BoostShot_Charged (강화, 탄 -1)
   └ 탄이 없으면       → BoostShot (일반)
```

- **Charged Variant를 비워두면** 그냥 누르는 순간 나가는 스킬이 됩니다 (레시피 A와 같음).
- Charged Variant가 있으면 **뗄 때** 발동합니다. 짧게 눌러도 손을 떼는 순간 나갑니다.
- 누르고 있는 동안에는 아직 스킬이 시작되지 않았으므로 **이동할 수 있습니다**.

## 6. 레시피 C — 홀드형 (누르고 있다가 뗌)

기획서: **누르고 있다가 뗌. 홀드 중 D 입력 시 탄 소모, 강화 확정.**

키를 누르는 순간 스킬이 시작되고(이동 불가), **손을 뗄 때 쿨타임이 시작**됩니다.

### 6-1. 먼저 "홀드 방식" 고르기

| Hold Mode | 누르는 동안 | 떼면 | 맞는 스킬 |
|---|---|---|---|
| **Charge Then Release** | 판정 없이 힘을 모음 | 선딜 → 활성 → 후딜 | 차지 샷, 레이저 샷 |
| **Sustain Active** | 선딜 후 **활성이 계속 유지**됨 (계속 때림) | 후딜 | 연속 펀치 |

```
Charge Then Release:  [ 차지 ...누르는 동안... ] →뗌→ [선딜][활성][후딜]
Sustain Active:       [선딜][ 활성 ...누르는 동안... ] →뗌→ [후딜]
```

### 6-2. 에셋 만들기

1. `Create > CSH > Skill > Hold Skill (홀드형 베이스)` → 이름 예: `RapidPunch`
2. 공통 칸 채우기
3. 맨 아래 **"홀드형"** 칸 채우기:

**홀드형 — 홀드**

| 칸 | 뜻 | 0이면 |
|---|---|---|
| **Hold Mode** | 6-1 표 참고 | |
| **Min Hold Frames** | 이것보다 짧게 누르고 떼면 **취소** (판정 없이 끝남) | 취소 없음 |
| **Early Release Cooldown Scale** | 취소됐을 때 쿨타임 비율. `1` = 전부, `0.5` = 절반, `0` = 없음 | |
| **Max Hold Frames** | 이만큼 누르고 있으면 안 떼도 **자동 발동** | 무제한 |

**홀드형 — 홀드 중 강화**

| 칸 | 뜻 |
|---|---|
| **Enhanced Variant** | 홀드 중 D를 누르면 나갈 강화 에셋. 비우면 강화 없음 |
| **Enhance Slot** | 강화 키. 기본 `Basic`(D) 그대로 |
| **Enhance Mode** | 아래 표 |

| Enhance Mode | D를 누르면 | 맞는 스킬 |
|---|---|---|
| **Swap And Continue** | 강화로 바뀌고, 홀드는 계속. 뗄 때 강화로 나감 | |
| **Swap And Release** | 강화로 바뀌고, **바로 뗀 것처럼** 발동 | 차지 샷, 레이저 샷 |
| **Finish And Chain** | 지금 동작을 끝내고 강화 에셋을 **이어서** 실행 | 연속 펀치 → 피니시 블로우 |

> 탄이 없을 때 D를 누르면 **그냥 무시**되고 홀드가 계속됩니다.
> 홀드 중 누른 D는 기본공격으로 나가지 않습니다.

**홀드형 — 끊김**

| 칸 | 뜻 |
|---|---|
| **Interrupt Cooldown Scale** | 떼기 전에 맞아서 끊겼을 때 쿨타임 비율. `1` = 전부, `0` = 없음 |

### 6-3. 강화 에셋 만들기 (Enhanced Variant를 쓸 때)

`Create > NYH > Combat > Action Data`로 만들고:

| 칸 | Swap And ... 모드 | Finish And Chain 모드 |
|---|---|---|
| Cylinder Cost | `1` | `1` |
| Cooldown Owner | 원본 홀드 에셋 | 원본 홀드 에셋 |
| Cooldown Frames | 원본과 **같은 숫자** (0이면 쿨타임 안 돔) | `0` 그대로 두면 원본 쿨타임이 돔 |
| Fallback Action | 비워둠 | 비워둠 |

### 6-4. 기획서 스킬 세팅 예시

> 아래 수치는 기획서 초안 기준 예시입니다. 확정 수치가 나오면 그 값으로 바꾸세요.

| 에셋 | 칸 | 값 |
|---|---|---|
| `RapidPunch` (Hold Skill) | Hold Mode | Sustain Active |
| | Active Frames | `6` 이상 (최소 한 번은 때리게) |
| | Hit Interval Frames | `6` (0.1초) |
| | Damage | `4` |
| | Max Hold Frames | `240` (4초) |
| | Cooldown Frames | `480` (8초) |
| | Enhanced Variant / Enhance Mode | `RapidPunch_Finisher` / Finish And Chain |
| `RapidPunch_Finisher` (Action Data) | Damage | `40` |
| | Cylinder Cost / Cooldown Owner | `1` / `RapidPunch` |

**레이저 샷** — 게이지 1초 충전, 충전 전에 떼면 취소(쿨 50%), 선딜 0.4초, 쿨 12초

| 에셋 | 칸 | 값 |
|---|---|---|
| `LaserShot` (Hold Skill) | Hold Mode | Charge Then Release |
| | Min Hold Frames | `60` (1초) |
| | Early Release Cooldown Scale | `0.5` |
| | Startup Frames | `24` (0.4초) |
| | Recovery Frames | `30` (0.5초) |
| | Cooldown Frames | `720` (12초) |
| | Enhanced Variant / Enhance Mode | `LaserShot_Enhanced` / Swap And Release |

**차지 샷** — 2.5초 경과 시 자동 발동, 쿨 7초

| 에셋 | 칸 | 값 |
|---|---|---|
| `ChargeShot` (Hold Skill) | Hold Mode | Charge Then Release |
| | Max Hold Frames | `150` (2.5초) |
| | Cooldown Frames | `420` (7초) |

> 차지 샷의 "차지 시간에 따라 3단계 피해(30/45/60)"는 칸만으로는 안 됩니다. 프로그래머 작업이 필요합니다 → [9장](#9-프로그래머용-새-흐름이-필요할-때)

## 7. 테스트하는 법

1. 씬을 플레이합니다.
2. **Console 창**을 열고 키를 눌러봅니다.

| 이런 로그가 찍히면 | 뜻 |
|---|---|
| `[SkillRunner] Player: '연속 펀치' 시작 (슬롯 LeftArm, ...)` | 탭형/홀드형 스킬이 정상 시작됨 |
| `[부스터 샷] Startup 9f → Active 3f → Recovery 21f` | 일반 Action Data가 정상 시작됨 |
| `... 쿨타임 중 — 남은 120f` | 쿨타임이라 막힘 (정상) |
| `... 탄 1발 필요(보유 0발) → '...'로 대체` | 탄이 없어 일반판정으로 나감 (정상) |
| `[SkillDriver] ... ISkillLoadout(PlayerSkillLoadout)이 없음` | 2장 4번이 빠짐 |

### 체크리스트

- [ ] 탭형: 짧게 → 일반 / 0.3초 이상 → 강화 / 탄 0일 때 길게 → 일반
- [ ] 홀드형: 누르는 동안 이동이 안 됨
- [ ] 홀드형: 최소 시간 전에 떼면 취소되고 쿨타임이 설정한 비율로 돔
- [ ] 홀드형: 최대 시간이 되면 안 떼도 발동
- [ ] 홀드형: 홀드 중 D → 강화 (탄 1 감소)
- [ ] 홀드 중 적에게 맞으면 끊김
- [ ] 해당 부위가 파괴되면 그 키가 안 나감

## 8. 안 될 때 (자주 하는 실수)

| 증상 | 원인 | 해결 |
|---|---|---|
| 키를 눌러도 아무 일도 없음 | Loadout 칸이 비어 있음 | 2장 5번 |
| | 예전 `Player Input Source`가 아직 붙어 있음 | 지우기 |
| | 쿨타임 중 / 부위 파괴 / 공중인데 Ground Only | Console 로그 확인 |
| 강화판정을 쓴 뒤 쿨타임이 안 돔 | 강화 에셋의 Cooldown Frames가 0 | 원본과 같은 숫자 넣기 |
| 강화를 써도 일반 쿨타임이 따로 돎 | 강화 에셋의 Cooldown Owner가 비어 있음 | 원본 에셋 넣기 |
| 길게 눌러도 강화가 안 나감 | 탄이 0 | 정상 동작 (일반으로 나감) |
| | Loadout에 강화 에셋을 넣음 | Loadout에는 **일반판정 에셋**을 넣기 |
| 짧게 눌렀는데 반응이 늦음 | 탭형은 뗄 때 발동함 | 정상. 즉시 나가야 하면 Charged Variant를 비우기 |
| 연속 펀치가 한 대도 안 맞음 | Sustain Active인데 Active Frames가 0 | 1 이상 (Console에 경고도 뜸) |
| 홀드 중 애니메이션이 먼저 끝나버림 | 아직 차지 포즈 연출이 연결 안 됨 | 아래 "알려진 제한" |

### 알려진 제한 (2026-10-27 기준)

1. **부스터 샷 장비 대체 시 길게 눌러도 강화가 안 나감**
   `BoostShotActionData`가 아직 탭형이 아니라서 그렇습니다. 프로그래머가 아래 한 줄을 바꾸면 해결됩니다.
   ```csharp
   // Assets/CSH/02.Scripts/02_/BoostShotActionData.cs
   public class BoostShotActionData : TapSkillData   // 기존: ActionData
   ```
   바꾼 뒤 `BoostShot.asset`의 Charged Variant에 `BoostShotEnhanced`, Charge Threshold Frames에 `18`.
   장비 대체 효과(`Action Replace`)의 **Slot Charged 칸은 이제 쓰이지 않습니다** (비워도 됨).

2. **홀드(차지) 동안 전용 포즈 애니메이션 없음**
   지금은 Animation Clip Name 하나가 시작부터 재생됩니다. 차지 포즈 → 발사 모션 분리는 연출 쪽(`RobotView`) 작업이 필요합니다.

3. **적/보스는 이 시스템을 쓰지 않음**
   적은 예전 방식 그대로입니다. 보스는 KKH 보스 베이스로 따로 진행됩니다.

## 9. 프로그래머용: 새 흐름이 필요할 때

칸(데이터)만으로 안 되는 스킬은 **러너**를 상속해서 만듭니다. 흐름은 베이스가 정하고, 바꾸고 싶은 순간의 함수만 채우면 됩니다 (템플릿 메서드).

### 9-1. 파일 구성

| 파일 | 역할 |
|---|---|
| `SkillData.cs` | 스킬 에셋 베이스. `EvaluateTrigger`(언제 시작할지), `CreateRunner`(무슨 흐름으로 돌지) |
| `SkillRunner.cs` | 흐름 템플릿. 선딜/활성/후딜, 비용 확정, 취소, 체인 |
| `TapSkillData.cs` | 탭형 |
| `HoldSkillData.cs` / `HoldSkillRunner.cs` | 홀드형 |
| `SkillDriver.cs` | 입력 → 시작 판정 → 러너 실행 (건드릴 일 거의 없음) |
| `SkillContext.cs` | 러너가 쿨타임·탄·위치에 접근하는 창구 |
| `SkillInputTypes.cs`, `PlayerSkillInputSource.cs`, `PlayerSkillLoadout.cs` | 입력, 슬롯 |

### 9-2. 매 프레임 순서

```
OnInput(입력)            ← 키 반응은 여기서
→ 구간 끝났나? → OnPhaseExit → OnPhaseEnter
→ OnPhaseTick
```

### 9-3. 예시: 차지 샷 3단계

```csharp
using UnityEngine;

[CreateAssetMenu(menuName = "CSH/Skill/Charge Shot", fileName = "ChargeShot")]
public class ChargeShotData : HoldSkillData
{
    [Header("차지 단계 (누른 프레임 이상이면 그 단계)")]
    [SerializeField] private int stage2Frames = 60;   // 1.0초
    [SerializeField] private int stage3Frames = 90;   // 1.5초
    [SerializeField] private ActionData stage2;       // 피해 45 에셋
    [SerializeField] private ActionData stage3;       // 피해 60 에셋

    public override SkillRunner CreateRunner() => new Runner(this);

    private sealed class Runner : HoldSkillRunner
    {
        private readonly ChargeShotData data;
        public Runner(ChargeShotData data) { this.data = data; }

        // 뗄 때 누른 시간으로 판정을 고른다. 1단계(피해 30)는 이 에셋 자신
        protected override ActionData SelectReleaseVariant(int heldFrames)
        {
            if (heldFrames >= data.stage3Frames && data.stage3 != null) return data.stage3;
            if (heldFrames >= data.stage2Frames && data.stage2 != null) return data.stage2;
            return Current;
        }
    }
}
```

2·3단계 에셋은 Cooldown Owner = 1단계 에셋, Cooldown Frames = 같은 숫자로 둡니다.

### 9-4. 자주 쓰는 훅과 도구

| 훅 (override) | 언제 |
|---|---|
| `SelectReleaseVariant(heldFrames)` | 홀드를 뗄 때 나갈 에셋 |
| `OnHoldTick(input)` | 홀드 중 매 프레임 (게이지, 공중 정지) |
| `OnHoldReleased(timedOut)` | 뗀 직후 (반동 이동 등) |
| `OnEnhanced()` | 홀드 중 강화 확정 직후 |
| `OnInput` / `OnPhaseEnter` / `OnPhaseTick` / `OnPhaseExit` / `OnEnd` | 일반 러너용 |
| `GetPhaseLength` / `GetNextPhase` | 구간 길이·순서 자체를 바꿀 때 |

| 도구 (호출) | 하는 일 |
|---|---|
| `Commit(variant)` | 쿨타임 시작 + 탄 소모 (그 에셋으로 바꾸면서) |
| `SwapTo(action)` | 판정·애니메이션 에셋 교체 |
| `Cancel(scale)` | 취소. 쿨타임을 scale 비율로 |
| `FinishAndChain(next, pay)` | 끝내고 next를 이어서 실행 |
| `RequestPhaseExit()` | 지금 구간을 이번 프레임에 끝냄 |

### 9-5. 지켜야 할 규칙

- **에셋(ScriptableObject)에 런타임 값을 저장하지 마세요.** 에셋은 플레이어·적이 같이 씁니다. 변하는 값은 러너 필드에 둡니다.
- 시간은 `Time.deltaTime`이 아니라 **프레임(`PhaseFrame`, `ElapsedFrames`)**으로 셉니다.
- 러너는 스킬당 하나를 재사용합니다. 상태 초기화는 `OnBegin`에서 하세요.
