# 리얼스틸 단축키 정리

> 작성 2026-11-16 · **재검토 2026-11-23** — 프로젝트 전체 스크립트에서 키를 읽는 코드를 다시 모아 확인한 값 (인스펙터에서 바꿀 수 있는 키는 기본값 · 프리팹 값 기준)
> 게임 안에서는 **Home**을 누르면 지금 씬에 있는 기능만 골라 같은 내용을 보여 준다 (`ShortcutHelpOverlay`)
> 대화 시스템 구조 · 확인 순서: `대화시스템_구현정리.md`

## 1. 필드 (고물상 · 집 · 길드 · 경매장)

| 키 | 기능 | 담당 |
|---|---|---|
| WASD / 방향키 | 이동 | SYS `RSSimpleCharacter` |
| Shift (누름) | 달리기 | SYS |
| Q / E | 카메라 45° 회전 (NPC · 문 앞, 대화 중에는 꺼짐) | SYS (LHM `CameraStepBlock`이 막음) |
| R / F (누름) | 카메라 기울이기 | SYS |
| + / - · 휠 | 줌 | SYS |
| 우클릭 드래그 | 카메라 돌리기 | SYS |
| Shift + Home | 카메라 초기화 | SYS |
| E | NPC · 기계와 상호작용 / 문 들어가기 · 나가기 / 고철 뒤지기 | LHM `PlayerInteractor` · `DoorInteractable`, KDU `ScrapInteractor` |
| Tab | 인벤토리 (Esc 닫기) | KDU `InventoryToggle` |
| I | 인벤토리 + 제작창 (Esc 닫기) | KDU `InventoryToggle` (`Canvas_Inventory` 두 번째 모드) |
| V | 스킬창 (Esc 닫기) | KDU `SkillWindowView` |
| M / O / Shift + R | 지도 / 달력 / 랭킹 | LJS `SystemUiOnOffManager` |
| Shift + S | 골드 수동 저장 | LSH `GlobalGold` |
| Space | 고철 미니게임 타이밍 | KDU `TimingBarMinigame` |
| Esc | 일시정지 메뉴 (돌아가기 · 환경설정 · 나가기). 대화 · 선택지 · 튜토리얼 · 지도 등 다른 창이 열려 있으면 그 창이 먼저 | YJW `PauseMenu` |
| F10 | 도움말 · 튜토리얼 다시 보기 | LHM `TutorialDirector` |
| Home | 단축키 안내 (Home · Esc 닫기) | LHM `ShortcutHelpOverlay` |

- 대화 · UI가 열려 있는 동안은 이동 · Tab · I가 잠긴다 (`FieldInputBridge`). 고물상 상점 창이 열린 동안은 잠그지 않음
- 대화 · 창 · 일시정지 중에는 NPC 이름표가 숨고 E가 동작하지 않음
- 예전에 적혀 있던 **C / K (제작창 / 상점창)는 없어짐** — YJW `CraftingUIManager`에 키 입력이 없고, 제작창은 KDU `InventoryToggle`의 I로 열림. 상점은 NPC 선택지에서만

## 2. 대화

| 키 | 기능 |
|---|---|
| Space · Enter · 좌클릭 | 다음 줄 / 글자 즉시 완성 |
| Esc | 스킵 (안 읽은 대사가 있으면 한 번 더 확인) |
| Ctrl (누름) | 읽은 대사 빨리감기 |
| Tab | 오토 |
| L | 백로그 (↑↓ · PgUp/PgDn · 휠로 스크롤, L · Esc 닫기) |
| LOG · AUTO · SKIP 클릭 | 대화창 오른쪽 버튼 (위 L · Tab · Esc와 같음) |

- 대화 시작 0.25초, 줄마다 0.12초는 입력을 무시 (연타 방지)

## 3. 선택 화면 (NPC 선택지 · 보스 레이스 · 난이도 · 시즌 전화)

| 키 | 기능 |
|---|---|
| 1 ~ 9 (키패드 포함) | NPC 선택지 바로 고르기 (번호가 붙은 선택지) |
| W/S · ↑↓ | 선택지 · 난이도 이동 |
| A/D · ←→ | 보스(지역) 카드 이동 |
| E · Space · Enter | 결정 |
| Esc | 나가기 · 뒤로 · 창 닫기 |
| Z | 시즌 시작 전화 받기 |
| Enter · Z · E / Esc | 예 · 아니요 창 결정 / 아니요 (←→ · W/S로 이동, Space로는 결정 안 함) |

## 4. 튜토리얼 · 컷신 · 메인 메뉴 · 로딩

| 화면 | 키 |
|---|---|
| 튜토리얼 창 | ← → (A/D) 이전 · 다음, Space · Enter · E 다음, Esc 닫기. **열린 동안 게임 정지** |
| 도움말 목록 (F10) | ↑↓ (W/S) 고르기, Enter · E · Space 보기, Esc 닫기 |
| 오프닝 컷신 | Space · Enter · 클릭 다음 (자동 진행), Esc 두 번 건너뛰기 → 끝나면 `Main_Home_Workshop` |
| 메인 메뉴 | 스플래시에서 아무 키, Esc 종료 확인 |
| 일시정지 메뉴 (Esc) | 버튼 클릭, Esc = 설정 창 닫기 → 메뉴 닫기 |
| 로딩 화면 | 100%가 된 뒤 **아무 키 · 클릭 · 패드 A/Start** = 다음 씬으로 (안내 문구 깜빡임) |

## 5. 경매장 (LSH)

| 키 | 기능 |
|---|---|
| E (등록직원 앞) | 1. 경매 (일반 · 주먹) 2. 옵션 3. 대화하기 4. 나가기 |
| Space · 좌클릭 | 경매 진행 넘기기 (버튼 위 클릭 제외) |
| Esc | 수리 창 닫기 |

## 6. 전투 (NYH · CSH, 사이드뷰)

| 키 | 기능 |
|---|---|
| ← / → | 이동 (같은 방향 두 번 = 대시) |
| ↑ | 점프 |
| Space | 회피 |
| D | 기본 공격 |
| Q / W (누름 = 차지) | 왼팔 / 오른팔 스킬 |
| E / R | 왼다리 / 오른다리 스킬 |

- NYH `PlayerInputSource` · CSH `PlayerSkillInputSource` 둘 다 같은 키

## 8. 겹치는 키 (2026-11-23 재확인)

| # | 키 | 겹치는 기능 | 영향 | 상태 |
|---|---|---|---|---|
| 1 | F12 | 테스트 패널 ↔ `Step09` 기록 초기화 | 패널을 열 때 대화 기록이 지워짐 | **해결** — 패널이 있으면 Step09 F12 꺼짐 |
| 2 | Ctrl + F12 | 받을 포상 추가 ↔ 테스트 패널 | — | **해결** — 패널은 Ctrl과 같이 누르면 무시 |
| 3 | Esc | 일시정지 메뉴 ↔ 대화 스킵 · 선택지 · 튜토리얼 · 보스 선택 · 백로그 · 지도 | 창이 닫히며 메뉴도 같이 열림 | **해결** — 다른 창(UI 스택 · 게임 정지)이 있으면 메뉴가 양보 |
| 4 | F10 | 튜토리얼 도움말 ↔ `Step09` 풀스크린 대사 테스트 | DialogueTest 계열 씬에서 둘 다 실행 | 남음 — LHM 테스트 키를 Shift+F10으로 옮기는 안 |
| 5 | F9 | 제작 테스트 재료 ↔ `Step09` 순위 구간 | 두 기능이 한 씬에 같이 있을 때만 | 같은 씬에 두지 않음 (현재 따로 있음) |
| 6 | 1 ~ 5 | NPC 선택지 번호 ↔ `Step09` 다음 토벌 난이도 | 테스트 프리팹 씬에서 선택지를 숫자로 고르면 난이도도 바뀜 | 남음 — 선택지가 열린 동안 테스트 키 무시하는 안 |
| 7 | J | `Step15` 관중 켜기 ↔ 시즌 보상 테스트(Ctrl + J) | — | 겹치지 않음 (Ctrl 유무로 구분, 서로 다른 씬) |
| 8 | Tab · I · E | 인벤토리 · 제작창 · 카메라 회전 ↔ 대화 | — | **해결** — 대화 중 잠금 · NPC 앞 카메라 회전 막기 |

- 다른 팀 파일은 수정하지 않았다 (YJW `PauseMenu`의 Esc 양보는 허락받고 수정)
