## 1 · 2. 새 게임 초기화 · 이어하기 (BUG-013 ~ 016)

**원인:** `MainMenuController.NewGame()`이 씬만 이동하고 저장 데이터를 지우지 않음. 이어하기는 인스펙터 고정값이라 세이브를 보지 않음.

**수정**
- 새 파일 `02.Scripts/MainMenu/GameSaveReset.cs`
  - `HasSave()`: `dialogue_save.json`(또는 `.bak`) 존재 여부
  - `ResetForNewGame()`: 대화 세이브 삭제 (시즌 변수 `race.id` · 보스 기록 포함) + 컷신 · 튜토리얼 본 기록(PlayerPrefs) 삭제 + KDU 인벤토리 초기화
  - 인벤토리: `InventoryHost`가 씬을 넘어 살아 있어서, 인스턴스를 없애고 `inventory.json` 삭제 후 Resources 프리팹으로 다시 만듦 → 시작 장비로 세팅 (KDU 코드 수정 없음)
  - 음량 · 그래픽 설정은 유지
- `MainMenuController.cs`: 이어하기 = 세이브 있을 때만. 새 게임 = 세이브가 있으면 확인창 → 초기화 → 씬 이동
- `MainMenuBuilder.cs`: "새 게임" 확인창 생성 (종료 확인창과 같은 함수 사용). **메인 메뉴 씬 재생성 완료** (`newGameWindow` 연결됨)

**남음:** 골드(`GlobalGold`)는 초기값을 LSH만 알아서 유지됨 → LSH에 초기화 함수 요청 필요

## 4. 토벌 출발 멈춤 (BUG-026 · 025)

**원인**
- 026: 대화 중 `FieldInputBridge`가 SYS `RSSimpleCharacter`를 끄면 애니메이터 `Speed`가 마지막 값에 멈춰 제자리 달리기
- 025: `HuntDeparture`가 동기 `LoadScene` → 로딩 동안 마지막 화면이 멈춤. LJS 로딩 화면은 프리팹으로만 있고 씬에 없었음

**수정**
- `FieldInputBridge.cs`: 이동을 막을 때 애니메이터 `Speed` = 0
- 새 파일 `02.Scripts/Dialogue/Interaction/SceneLoader.cs`: 로딩 화면이 있으면 사용 → 없으면 지정 프리팹 생성 → 그것도 없으면 비동기 로드 (LJS는 이름 · 리플렉션으로 호출)
- `HuntDeparture.cs`: 출발 시 `SceneLoader` 사용, `loadingScreenPrefab` 칸 추가
- `DialogueSystem.prefab`: 위 칸에 `LJS/04. Prefab/LodingManager.prefab` 연결 (참조만)

**확인 필요:** 진입 대사는 원래 클릭 · Space로 넘기는 구조. 제보의 "키 입력해야 넘어감"이 대화창이 안 보였던 경우라면 별도 수정 필요

## 5. 길드 출구 (BUG-035)

**원인:** 길드 씬에 출구 기능이 없음. 나가는 방법이 LJS 지도(M키)뿐이고 화면 안내 없음.

**수정**
- `League_Lobby.unity`: 입구 자리(`SLOT_Entrance_입구`)에 `길드 출구 ([E] 나가기)` 추가 → `Map_Test`로 이동. 반경 1.2m (시작 위치와 겹치지 않게)
  - `SLOT_Gate_경기장문`은 경기장으로 가는 셔터문이라 출구로 쓰지 않음
- `DoorSetup.cs` · `DialogueToolWindow.cs`: 문 도구가 길드 씬에서 입구 자리에 같은 출구를 만들도록 확장 (씬을 옮긴 뒤 다시 만들 때 사용)

**수정**
- 새 파일 `02.Scripts/Dialogue/Interaction/CraftingWindowBridge.cs`: YJW 제작 · 수리창 열기 · 닫기 공용 (작업대와 공유)

## 7. 클리어 데이터 저장 (BUG-031)

**원인**
- 전투 씬에 `BossProgressStore`가 없어 KKH `BattleSettlementProcessor`의 `RecordHunt` 호출이 닿지 않음
- 보스별 도전 · 패배 · 최고 난이도 · 지역 클리어가 메모리에만 있어 씬 이동 시 사라짐
- 도전 횟수는 실제 출발 흐름에서 올리는 곳이 없었음 (테스트 키만)
- KKH가 난이도를 소문자(`veryeasy`)로 넘겨 "아주 쉬움" 클리어가 기록되지 않음

**수정** (KKH 코드 수정 없음)
- `BossProgressStore.cs`: 기록을 `boss_progress.json`(persistentDataPath)에 저장 · 불러오기
  - 전투 씬(`BattleManager`가 있는 씬)에 기록기가 없으면 자동 생성
  - 대화 매니저가 없는 전투 씬에서는 대사 변수(`hunt.*`)를 대기 결과로 저장 → 필드 씬 기록기 `Start`에서 반영
  - 난이도 대소문자 맞춤 (`veryeasy` → `veryEasy`)
- `HuntDeparture.cs`: 전투 출발 시 도전 횟수 +1
- `GameSaveReset.cs`: 새 게임 시 `boss_progress.json`도 삭제

**확인:** 토벌 → 승리/패배 → 필드 복귀 → 난이도 창의 최고 기록 · 패배 수, 3패 힌트, 패배 반응 대사

## 8. 전투 난이도 표시 Normal 고정 (BUG-027)

**원인:** 난이도 값 자체는 정상 전달됨 (`SetPreBattleDifficulty` → KKH `BattleManager` · `BossControllerBase`가 읽어 적용). 화면 표시는 LJS `BattleUiCanvas.prefab`의 `Difficulty/Text (TMP)`가 `"Normal"` 고정 글자이고, 바꾸는 코드가 없음.

**수정** (LJS · KKH 파일 수정 없음)
- 새 파일 `02.Scripts/BossRace/BattleDifficultyLabel.cs`: 전투 씬(`BattleManager`가 있는 씬)이 열리면 `Difficulty` 아래 글자를 실제 난이도(Very Easy · Easy · Normal · Hard · Hell)로 교체

**확인:** 토벌 신청에서 Normal이 아닌 난이도 선택 → 전투 화면 오른쪽 위 난이도 글자 · 결과창 요약의 난이도
