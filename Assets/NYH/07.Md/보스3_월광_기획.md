## 0\. 공통

### 0.1 컨셉

- **디자인**: 마에스트로 (지휘자)  
- **악장 컨셉**: 베토벤 「월광 소나타」 3악장 구성을 페이즈로 사용  
- **등장 객체**: 음표, 악기, 지휘자

| 페이즈 | 원곡 성격 | 보스 페이즈의 결 |
| :---- | :---- | :---- |
| 1악장 | 느리고 고요함, 셋잇단 아르페지오 | 느린 탄, 큰 곡선, 긴장감 |
| 2악장 | 가볍고 경쾌함 | (작성 예정) |
| 3악장 (**헬 전용**) | 몰아치는 프레스토 | (작성 예정) |

음원은 자체 편곡·녹음을 씁니다. 작곡은 퍼블릭 도메인이지만 기존 음반 녹음에는 저작권이 있을 수 있습니다.

### 0.2 나노봇 표현 원칙

| 원칙 | 내용 |
| :---- | :---- |
| 강점 | 형태가 고정되지 않는 표현: **곡선**, 여러 입자가 흩뿌려지는 **탄막** |
| 약점 | 스프라이트에 의존한 딱딱한 형체 |
| 3단 구조 | 모든 패턴은 **흐름 → 형태 → 붕괴** 순서로 연출 |
| 주인공 객체 | 한 번에 **주인공 객체 1개**에 집중, 나머지 봇은 입자(탄막, 모래)로 처리 |
| 실루엣 | 단순하게, 짧게 유지, 끝은 흩어지게. 턱시도 같은 인체 디테일 금지 |
| 지휘자 표현 | 모양이 아니라 **몸짓**으로 표현: 덩어리 몸 \+ 지휘봉 선 \+ 손 역할의 작은 덩어리 2개 \+ 흩날리는 꼬리 줄기 2개 |
| 판정 입자 | 판정이 있는 입자는 뭉치 단위로 묶고 발광으로 구분. 장식 입자와 섞지 않음 |

### 0.3 타격 부위 배분 (파츠 내구도)

| 부위 | 패턴 | 이유 |
| :---- | :---- | :---- |
| 머리 | 1악장 달빛 커튼 | 천장에서 쏟아짐 |
| 왼팔 | 1악장 음표 공격 | 몸 높이로 날아오는 직선탄 |
| 오른팔 | 1악장 거대 지휘봉 | 휘두르는 접촉 공격 |
| 왼다리 | 1악장 첫 큐 광역기 | 바닥에서 터지는 충격 |
| 오른다리 | (2악장에서 배정) | \- |

### 0.4 페이즈 진행 규칙

| 항목 | 규칙 |
| :---- | :---- |
| 체력 구조 | 악장마다 **체력 게이지 100%를 새로** 가짐 |
| 악장 종료 | 보스 HP가 **1에서 고정**됨 (0이 되지 않음). 이후 피해 무시 |
| 다음 악장 진입 | HP가 1에서 **100%로 회복**되며 다음 악장 시작 |
| 진행 범위 | 아주 쉬움\~어려움: 1악장 → 2악장 (2악장 HP 0으로 클리어) / 헬: 1악장 → 2악장 → 3악장 |

**전환 연출 (제안)**

| 단계 | 내용 | 보스 상태 |
| :---- | :---- | :---- |
| ① HP 1 고정 | 진행 중인 패턴을 즉시 중단 | 무적 |
| ② 붕괴 | 지휘자가 모래로 무너짐 | 무적 |
| ③ 재구성 | 모래가 다시 쌓아 올라가는 동안 **HP 게이지가 1 → 100%로 차오름** (쌓아 올리기와 게이지 회복을 동기화) | 무적 |
| ④ 다음 악장 | 다음 악장의 첫 큐로 이어짐 | 무적 해제 |

- 무너졌다가 다시 쌓이는 연출이라, 체력 회복이 갑작스럽지 않고 나노봇 원칙(붕괴 → 흐름)에도 맞습니다.  
- HP 1 고정 덕분에 큰 피해 한 방으로 악장을 건너뛰는 일이 없습니다.

### 0.5 2악장 → 3악장 전환: 가짜 격파 (헬 전용)

헬에서는 2악장 HP가 0이 되면 클리어처럼 보이는 가짜 격파 연출 뒤에 3악장이 시작됩니다. 다른 난이도에서는 2악장 HP 0이 그대로 클리어입니다.

| 단계 | 내용 | 보스 상태 |
| :---- | :---- | :---- |
| ① 격파 | 2악장 HP 0\. 지휘자가 모래로 완전히 무너지고 2악장 음악이 끝남 | 무적 |
| ② 커튼콜 | 관중 환호와 박수 말풍선. 클리어한 것처럼 보이는 순간 | 무적 |
| ③ 정적 | 환호가 잦아들고 완전한 정적 (약 2초) | 무적 |
| ④ 각성 | 월광 3악장(프레스토)이 갑자기 몰아치듯 시작되고, 모래가 솟구쳐 지휘자가 다시 만들어짐. HP 게이지가 0 → 100%로 차오름 | 무적 |
| ⑤ 3악장 | 3악장 첫 패턴 시작 | 무적 해제 |

- 가짜 격파 중에 **실제 클리어 결과 UI(보상, 랭킹 점수 창)는 띄우지 않습니다.** 결과 창까지 속이면 랭킹 기록과 헷갈리고 기만적으로 느껴질 수 있어서, 속임수는 관중 반응까지만 씁니다.  
- 원곡 3악장이 조용한 2악장 끝에서 갑자기 몰아치며 시작하는 구조를 연출에 그대로 씁니다.  
- 첫 큐의 "정적 → 빰"과 같은 문법(정적 → 폭발)을 반복해서, 보스 전체의 연출 정체성으로 삼습니다.

### 0.6 목표 클리어 시간과 악장별 HP

**목표 클리어 시간: 5\~10분**

| 난이도 | 목표 시간 (제안) | 진행 악장 |
| :---- | :---- | :---- |
| 아주 쉬움 | 약 5분 | 1 → 2 |
| 쉬움 | 약 5\~6분 | 1 → 2 |
| 보통 | 약 6\~7분 | 1 → 2 |
| 어려움 | 약 7\~8분 | 1 → 2 |
| 헬 | 약 9\~10분 | 1 → 2 → 3 |

**악장별 시간 배분 (제안)**

| 난이도 | 1악장 | 2악장 | 3악장 |
| :---- | :---- | :---- | :---- |
| 아주 쉬움 \~ 어려움 | 45% | 55% | \- |
| 헬 | 30% | 35% | 35% |

**악장별 최대 HP 산정식**

```
악장 최대 HP = 악장 목표 시간(초) × 기준 DPS × 딜 가능 비율
```

&nbsp;

| 변수 | 의미 |
| :---- | :---- |
| 기준 DPS | 해당 난이도 권장 파츠 등급으로 기본기와 파츠 스킬을 섞어 칠 때의 초당 피해 |
| 딜 가능 비율 | 악장 시간 중 보스를 실제로 칠 수 있는 시간 비율. 무적 연출, 배경 이동, 회피 시간을 뺀 값 (1악장 임시 0.5) |

예시 (보통, 1악장): 목표 6.5분 × 45% ≈ 175초 → 175 × 기준 DPS × 0.5

- 딜 가능 비율은 패턴 순환이 확정된 뒤 실제 플레이로 측정해서 보정합니다.  
- 지휘봉 파괴 그로기처럼 **딜이 몰리는 구간이 있으면 실제 시간이 짧아지므로**, 그로기 성공을 가정한 시간과 실패를 가정한 시간을 둘 다 재서 목표 범위 안에 들어오는지 확인합니다.  
- 전투가 길기 때문에 재도전 피로를 줄이는 장치(첫 큐 쌓아 올리기 단축 등)를 계속 유지합니다.

## 1\. 1악장

### 1.1 개요

| 항목 | 내용 |
| :---- | :---- |
| 분위기 | 원곡 1악장의 고요함. 느린 탄과 큰 곡선 |
| 시작 | 첫 큐 (입장 연출 \+ 광역기) |
| 패턴 | 거대 지휘봉 · 음표 공격 · 달빛 커튼 |
| 기믹 | 거대 지휘봉 파괴 → 그로기 |
| 종료 | HP 1에서 고정 → 전환 연출 → HP 100%로 2악장 시작 (0.4절) |

**패턴 순환 (제안)**

```
첫 큐 → 음표 공격 → 달빛 커튼 → 음표 공격 → 거대 지휘봉 → (음표 공격부터 반복)
```

- 거대 지휘봉은 그로기 기회가 걸린 패턴이라 순환마다 1회로 제한합니다.  
- 탄막 두 개(음표, 커튼) 사이에는 항상 다른 패턴을 하나 끼웁니다.

### 1.2 첫 큐 (입장 연출 \+ 광역기)

| 항목 | 내용 |
| :---- | :---- |
| 유형 | 연출 \+ 광역기 |
| 등장 객체 | 바이올린(좌) · 지휘자(중앙) · 하프(우) |
| 타격 부위 | 왼다리 |
| 모티브 | 실제 클래식 공연에서 지휘자가 지휘봉을 들면 객석이 숨을 죽이고, 첫 음에서 긴장이 터지는 순간 |

**악기 선택: 피아노 → 하프 (확정)**

- 피아노는 건반 같은 각진 구조물이라 나노봇 원칙과 맞지 않습니다.  
- 하프는 **큰 곡선 몸체**라 실루엣이 단순하고 곡선적입니다. 원곡 1악장의 아르페지오와 하프 연주의 이미지도 잘 맞습니다.

**연출 흐름**

| 단계 | 시간 | 내용 | 보스 상태 |
| :---- | :---- | :---- | :---- |
| ① 흐름: 쌓아 올리기 | 약 4초 | 입장하면 바닥의 모래에서 세 객체가 **모래성 쌓듯 아래에서 위로** 올라옴 | 무적 |
| ② 형태: 완성 | \- | 바이올린, 지휘자, 하프가 완성됨 | 무적 |
| ③ 정적 | 5초 | 음악과 관중 말풍선이 멈춤. 지휘자가 지휘봉을 **천천히 위로** 들어 올림 (3.5초) | 무적 |
| ④ 예고 | 1.5초 | 지휘봉이 정점에서 **멈춤**. 이 순간 바닥에 **광역 범위가 표시**됨 | 무적 |
| ⑤ 공격: 빰 | 순간 | 지휘봉을 강하게 내리치는 이펙트 \+ "빰" 효과음 \+ 음악 시작. 세 객체 주변 광역 폭발 | 무적 |
| ⑥ 붕괴 | 약 1.5초 | 바이올린과 하프가 무너지고, 봇이 흘러서 지휘자에게 흡수됨. 관중 환호 말풍선 | 무적 해제 → 전투 시작 |

**판정**

| 항목 | 내용 |
| :---- | :---- |
| 범위 | 세 객체 각각의 중심에서 원형 범위 (임시 반경 3m) |
| 안전지대 | 객체 사이의 **틈** 두 곳 |
| 회피 | Space 회피 무적으로도 피할 수 있음 |
| 피해 | 중간 (첫 패턴이라 치명적이지 않게) |

**난이도별**

|  | 아주 쉬움 | 쉬움 | 보통 | 어려움 | 헬 |
| :---- | :---- | :---- | :---- | :---- | :---- |
| 틈 너비 | 넓음 (4m) | 넓음 (3.5m) | 보통 (3m) | 좁음 (2m) | 매우 좁음 (1.2m, 사실상 회피 권장) |
| 정점 정지 | 1.5초 | 1.5초 | 1.5초 | 1.5초 | 1.5초 |

정점 정지 1.5초는 이 패턴의 상징이라 전 난이도 고정입니다.

**재도전 처리**

- 첫 입장: 전체 연출  
- 재도전: ① 쌓아 올리기만 빠르게 진행(약 1.5초). **③ 정적과 ④ 예고는 그대로 유지**해서 긴장감은 남깁니다.

**구현 메모**

- 악기 실루엣은 리그 그림 부위 또는 덩어리 부위로, 곡선 실루엣만 씁니다(줄, 건반 같은 디테일 없음).  
- 쌓아 올리기는 자리표를 **아래쪽부터 채우는 순서**로 정렬해야 합니다. 현재 자리표는 가운데부터 채우므로 정렬 옵션을 추가해야 합니다.  
- 범위 표시는 바닥 데칼(UI)로 처리합니다.  
- 관중 말풍선 시스템과 연동: ③에서 정지, ⑥에서 환호 바크.

### 1.3 거대 지휘봉

| 항목 | 내용 |
| :---- | :---- |
| 유형 | 파훼형 \+ 기믹 (지휘봉 파괴 → 그로기) |
| 주인공 객체 | 지휘봉 |
| 타격 부위 | 오른팔 |

**연출 흐름**

| 단계 | 내용 | 보스 상태 |
| :---- | :---- | :---- |
| ① 흐름 | 보스의 몸과 지휘봉이 중앙에서 봇을 끌어모아 거대해짐 | 피격 가능 |
| ② 이동 | 보스가 **배경(뒤판)으로 빠짐**. 지휘봉은 앞판에 남음 | 보스 무적 |
| ③ 예고 | 궤적이 **희미한 선**으로 먼저 표시됨 (1.0초). 기준점은 패턴 시작 순간의 플레이어 위치로 **고정** | 보스 무적 |
| ④ 형태: 공격 | 지휘봉 끝이 8자(세로) 또는 무한대(가로) 궤적을 그리며 플레이어 주변을 이동. 배경의 보스는 몸 전체로 지휘하는 동작 | 보스 무적, 지휘봉 피격 가능 |
| ⑤ 반복 | 궤적 2\~3회 (난이도별) | \- |
| ⑥ 붕괴 | 보스와 지휘봉이 모래로 무너진 뒤 중앙에서 원래 크기로 재생성 | 피격 가능 |

**판정과 파훼**

| 항목 | 내용 |
| :---- | :---- |
| 판정 | 지휘봉 전체에 닿으면 피해 |
| 파훼 | 궤적을 읽고 점프나 회피로 피함. 8자와 무한대는 예고선 모양으로 구분 |
| 지휘봉 체력 | 있음. 반복 횟수 안에 집중하면 부술 수 있는 수준 (임시: 보스 최대 HP의 5%) |
| 파괴 보상 | 지휘봉이 부서지면 패턴이 즉시 끝나고 보스가 중앙에 떨어져 **그로기 (임시 4초)** |
| 파괴 실패 | 반복이 끝나면 ⑥으로 정상 종료 (그로기 없음) |

**난이도별**

|  | 아주 쉬움 | 쉬움 | 보통 | 어려움 | 헬 |
| :---- | :---- | :---- | :---- | :---- | :---- |
| 궤적 반복 | 2회 | 2회 | 3회 | 3회 | 3회 |
| 궤적 속도 | 느림 | 느림 | 보통 | 빠름 | 빠름 \+ 회차마다 가속 |
| 예고선 | 1.0초 | 1.0초 | 1.0초 | 0.8초 | 0.6초 |

**지휘봉 두께**: 손잡이는 굵고 끝으로 갈수록 가는 **테이퍼 형태**입니다. 가는 선은 봇 사이가 비어 끊겨 보일 수 있으므로, 봇이 모자라면 굵기 대신 길이를 줄입니다.

**지역 2 쿄다이와의 차별화**: 쿄다이는 처음부터 끝까지 배경에 있는 본체입니다. 마에스트로는 이 패턴에서만 잠깐 배경으로 빠지고, 배경에서도 지휘 동작을 계속 보여 줍니다.

**구현 메모**

- 지휘봉: 줄기 A `TubeGuide` \+ 휘두르기 사슬 (끝이 늦게 따라와 곡선이 부드러워짐)  
- 궤적: 리사주 곡선. 무한대는 x \= A·sin(t), y \= B·sin(2t). 8자는 x와 y를 바꿈  
- 판 배치: 보스는 뒤판, 지휘봉은 앞판 (인수인계서의 판 정하기, 화면 뒤 공격의 거리감 값 활용)  
- 지휘봉은 보스 본체와 별도의 피격 대상으로 등록하고 체력을 따로 가짐

### 1.4 음표 공격

| 항목 | 내용 |
| :---- | :---- |
| 유형 | 탄막형 |
| 주인공 객체 | 음표 |
| 타격 부위 | 왼팔 |

**연출 흐름**

| 단계 | 내용 |
| :---- | :---- |
| ① 흐름 | 지휘자가 지휘봉을 **천천히, 크게 한 번** 휘두름. 휘두르는 궤적을 따라 봇이 흘러나옴 |
| ② 형태 | **휘두르기 1번에** 궤적 위 공중에 음표 N개가 차례대로 생성됨 (N은 난이도별: 아주 쉬움 3개부터 한 단계마다 1개씩 증가) |
| ③ 예고 | 생성된 순서대로 하나씩 **그 음표의 음이 효과음으로 울리고, 동시에 음표가 반짝임** |
| ④ 공격 | 음이 울린 음표가 그 순간의 플레이어 위치를 향해 **직선 비행** |
| ⑤ 붕괴 | 플레이어나 벽·바닥에 닿으면 입자로 흩어지고, 모래가 되었다가 재흡수됨 |
| 종료 | 휘두르기 1번이 끝나면 다음 패턴으로 |

**음표 종류: 모양 \= 속도**

소리를 끈 플레이어도 속도를 읽을 수 있도록 음표 모양으로 속도를 구분합니다.

| 음표 | 속도 (임시) | 크기 |
| :---- | :---- | :---- |
| 온음표 𝅝 | 3 m/s (가장 느림) | 큼 |
| 4분음표 ♩ | 5 m/s | 보통 |
| 8분음표 ♪ | 8 m/s (가장 빠름) | 작음 |

- 음의 높이는 **월광 1악장 선율**에 맞춥니다. 음표 공격이 곧 곡의 한 소절이 됩니다.

**난이도별**

|  | 아주 쉬움 | 쉬움 | 보통 | 어려움 | 헬 |
| :---- | :---- | :---- | :---- | :---- | :---- |
| 음표 수 | 3 | 4 | 5 | 6 | 7 |
| 음표 구성 | 온음표 위주 | 온음표 \+ 4분 | 4분 위주 \+ 8분 1 | 4분 \+ 8분 2 | 8분 위주 |
| 음표 사이 간격 | 1.0초 | 0.9초 | 0.8초 | 0.7초 | 0.6초 |

**구현 메모**

- 음표: `Fire` 탄 뭉치를 음표 실루엣으로 성형 (실루엣이 단순한 음표만 사용)  
- 효과음과 반짝임은 같은 프레임에 재생 (소리 없이도 순서를 읽을 수 있게)  
- 맞거나 닿은 탄은 모래(`NanoSandJob`)를 거쳐 재흡수

### 1.5 달빛 커튼

| 항목 | 내용 |
| :---- | :---- |
| 유형 | 탄막형 (안전지대 이동) |
| 주인공 객체 | 커튼 (흘러내리는 입자) |
| 타격 부위 | 머리 |

**연출 흐름**

| 단계 | 시간 (임시) | 내용 |
| :---- | :---- | :---- |
| ① 흐름 | 1.0초 | 지휘자가 지휘봉을 위로 듦. 봇이 천장으로 흘러올라 달빛 띠를 만듦 |
| ② 예고 | 1.0초 | 천장에서 **틈 위치에 빛 기둥**이 비침 (안전지대 미리보기) |
| ③ 형태: 공격 | 6초 | 입자가 커튼처럼 흘러내림. 커튼 사이 **틈이 안전지대**이고, 틈이 천천히 좌우로 이동 |
| ④ 붕괴 | 1.0초 | 커튼이 바닥에 모래로 쌓였다가 지휘자에게 재흡수됨 |

**판정과 파훼**

| 항목 | 내용 |
| :---- | :---- |
| 판정 | 흘러내리는 커튼 입자에 닿으면 피해 (1회 피격 후 무적 시간 적용) |
| 파훼 | 틈을 따라 이동. 회피 무적으로 커튼을 가로질러 다른 틈으로 옮길 수도 있음 |
| 입자 구분 | 판정 있는 커튼은 발광 입자 뭉치. 바닥에 쌓인 모래는 판정 없음 |

**난이도별**

|  | 아주 쉬움 | 쉬움 | 보통 | 어려움 | 헬 |
| :---- | :---- | :---- | :---- | :---- | :---- |
| 틈 수 | 2 | 2 | 1 | 1 | 1 |
| 틈 너비 | 3m | 2.5m | 2.5m | 2m | 1.5m |
| 이동 속도 | 느림 | 느림 | 보통 | 보통 | 빠름 |
| 방향 전환 | 없음 | 없음 | 1회 | 2회 | 무작위 |

**구현 메모**

- 커튼: 리그 줄기 부위(세로) 여러 개 또는 무리 부위. 흘러내리는 입자는 낙하 봇  
- 커튼에 봇이 많이 들어가므로 패턴 중 지휘자 본체가 작아짐 → 본체 최소 크기 상한 필요  
- 빛 기둥 예고는 셰이더 발광 또는 UI 오버레이
