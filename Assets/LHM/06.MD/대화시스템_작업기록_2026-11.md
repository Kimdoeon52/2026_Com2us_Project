# 대화 시스템 작업 기록 (2026-11-13 ~ 11-16)

LHM 폴더 안에서 진행한 대화 시스템 · UI · 사운드 작업을 정리한 기록입니다.
모든 기능은 **대화 툴**(`Tools/Dialogue/대화 툴 열기`) 버튼으로 적용합니다.

> **상태 표시**: 이번 작업은 모두 컴파일 확인(LHM 오류 0건)까지만 했고, **Unity Play 확인 전**입니다. 직접 확인한 항목은 따로 적었습니다.

## 1. 튜토리얼 화면

- 영상(또는 프레임 이미지) + 이전 / 다음 + 진행 점 + 설명이 있는 RS-OS 스타일 튜토리얼 창.
- 데이터: `TutorialGuide` ScriptableObject (`Create > RealSteel/Tutorial Guide`). 샘플 `03.Data/Tutorial/Tutorial_Basic.asset` (4단계).
- 조작: ← / → (A / D), 확인 = 다음, 취소 = 닫기. 첫 단계는 이전 숨김, 마지막은 "완료".
- 테스트 키: Insert = 열기, Shift+Insert = 본 기록 초기화 (에디터 · 개발 빌드만).
- 파일: `02.Scripts/Tutorial/` (TutorialGuide, TutorialPanel, TutorialTest, Editor/TutorialSetup) → 프리팹 `05.Prefab/Tutorial/TutorialCanvas.prefab`.

## 2. 메인 메뉴 씬 (Heat UI)

- 스플래시(아무 키) → 홈(새 게임 · 이어하기 · 설정 · 크레딧), Esc 종료 확인.
- 설정: 해상도 · 화면 모드 · 수직 동기화 · 전체 음량.
- 씬: `01.Scene/MainMenu.unity` (대화 툴 "메인 메뉴"로 다시 만들 수 있음).
- 홈 버튼 이미지를 프로젝트 안 이미지로 채움 (배경 · 새 게임 · 이어하기 · 설정 · 크레딧).
- 고친 오류: 만들다 실패한 씬을 Play할 때 PanelManager 오류 → 에디터 '가짜 null' 문제(`GetComponent ?? AddComponent`)를 `TryGetComponent`로 수정, 실패하면 빈 씬으로 교체.
- **주의**: Heat 폴더가 git에 올라가 있지 않음 → 메인 메뉴 코드만 커밋하면 팀원 컴파일이 깨짐. Build Settings에 MainMenu · OpeningCutscene · JunkShop_Map 씬 추가 필요.

## 3. Heat UI 에셋 정리

- 메인 메뉴가 쓰지 않는 Heat 파일 삭제 (코드 · 에디터 · Resources는 유지, 참조를 끝까지 따라가 필요한 것만 남김).
- 원본 전체 백업은 작업 당시 임시 폴더에 보관 (필요하면 Asset Store에서 다시 받기).

## 4. 대사 미리보기 창 (조건 시뮬레이터)

`Tools/Dialogue/대사 미리보기` 또는 대화 툴 → 데이터 도구

- **왼쪽**: 변수 값을 Play 없이 바꿈 (기본값과 다르면 노란색, ↺ 되돌리기). "조건에 쓰인 변수만" 필터.
- **오른쪽 탭**
  - **풀에 말 걸기**: 나올 대사 + 이유, 후보 전체 순위 (통과 / 소비됨 / 조건 불충족과 이유). 클릭하면 조건 O/X · 대사 전체 · 지문.
    - `조건 맞추기` (조건이 참이 되게 변수 자동 설정), `본 것으로 +1`, `말 걸기` (게임처럼 소비해서 대사 순환 확인)
  - **00시 이벤트**: `dialogue_triggers.json` 기준 오늘 밤 대기열 (스토리 → 시스템 → 말풍선 순), `00시 지나기`
- **저장된 상황**: 변수 묶음을 이름 붙여 저장 · 불러오기 · 삭제. 팀 공용 파일 `03.Data/Dialogue/Preview/preview_presets.json`.
- **게임 값 가져오기**: Play 중 DialogueManager의 변수 · 기록 복사 (쿨다운 시각 제외).
- JSON 파일이 바뀌었을 때만 자동으로 다시 읽음.
- 판정은 게임과 같은 `DialogueSelector` 함수를 그대로 사용 (비교 · 설명 함수를 public으로 변경).

- 왼쪽: 화자 칭호 + 하늘색 지문. 오른쪽: **LOG · AUTO · SKIP 버튼(마우스 클릭 가능)**. 오른쪽 아래: **SPACE · CLICK ▼** (줄이 다 나왔을 때만, 위아래로 움직임).

- 하데스 · RS-OS 스타일은 끄기만 함. RS-OS 스타일을 다시 적용하면 원신 스타일이 꺼지고 원래 배치로 돌아감.
- 버튼 클릭은 `DialogueBoxControls`가 처리하고 DialogueBox가 매 프레임 물어봄 → 버튼 클릭이 '다음 줄'로 같이 넘어가지 않음.
- 하데스 스타일이 남아 있던 곳: DialogueCanvas 프리팹(전환 완료), `01.Scene/DialogueTest.unity`(현재 씬 버튼으로 전환).

## 6. 지문 (direction)

대사 줄에 `direction`만 적으면 칭호 아래 하늘색 `[ ... ]`로 표시. 없으면 숨김.

```json
{ "speaker": "receptionist", "textKey": "guild.greeting_busy.1", "direction": "서류 더미를 넘기며 눈도 안 마주치고" }
```

- CSV에 `direction` 열 추가 (expression 옆). 예전 CSV도 그대로 가져오기 가능.
- 샘플: `guild_npc.json` 접수원 대사 3줄.
- 문자열 테이블이 아닌 대사 풀 JSON에 직접 적음 (지금은 한국어만이라 단순하게). 다국어 시 키 방식으로 옮겨야 함.
- 빌드 전 **데이터 패킹** 다시 실행 필요.

## 7. 작업대 NPC (제작 · 수리 · 나가기)

E → 대화창 **"작업대: ……"** → 대사가 떠 있는 채로 선택지 **1. 제작하기 2. 수리하기 3. 나가기**

- 숫자 키 1~9로 바로 선택 가능 (**모든 NPC 선택지에 번호가 붙음**. 끄려면 NpcMenu의 `Numbered` 해제).
- `NpcInteractable`에 **인사 대사 풀(greetingPoolId)** 칸 추가 → 채우면 선택지 전에 대사가 먼저 나옴 (다른 NPC에도 사용 가능).
- 데이터: `workbench.json` (……), `strings_ko.json` (작업대 이름 · 칭호 `WORKBENCH // GARAGE` · 메뉴 문구).

### 제작 · 수리 창 연결 (Home_Workshop 1)

대화 툴 → 작업대 → **씬의 작업대 오브젝트에 연결 + 제작 · 수리 창**

1. `01.Scene/TEST/Home_Workshop 1.unity` 열기 → 버튼 → 대상 `SLOT_Workbench_작업대` 확인 → 연결 → Ctrl+S
2. 작업대 E → 1. 제작하기 = YJW 제작창(+인벤토리) / 2. 수리하기 = YJW 수리창 → 닫기 또는 Esc로 종료

- 기능은 **`SLOT_` 소품 자리**에 붙임 (`임시_` 모형은 진짜 모델이 들어오면 자동으로 꺼지므로).
- 제작 · 수리 창이 없으면 **LJS JunkShop_Map에서 6개 묶음을 복사**해 옴: Canvas_Window · CraftingManager · InventorySystem · Canvas_Inventory · Canvas_Equipment · GoldSystem (원본 씬은 저장하지 않고 닫음).
  - 창 겹침 관리자(ExclusiveWindowManager)는 캐릭터 · 조명 · 고철장까지 끌고 와서 제외.
  - 복사해 온 창은 Ctrl+Z 불가 → 되돌리려면 저장하지 말고 씬 다시 열기.
- 실행 중에는 `NpcChoiceMenu`가 씬의 `CraftingUIManager`를 **이름으로 찾아** 그 열기 · 닫기 함수를 호출 (YJW 코드 수정 없음, 인벤토리 배치 · 재료 반환도 그대로 동작).
- 대화 시스템이 꺼져 있거나 없는 씬이면 **대화 시스템 프리팹을 배치 + 씬 연결**, EventSystem도 없으면 추가.

## 8. E 키 카메라 회전 충돌 수정

- 증상: 대화할수록 카메라 각도가 점점 꺾임.
- 원인: SYS `RSSimpleCharacter.cs`가 **Q/E를 카메라 45° 회전**으로 사용 → 상호작용 키 E와 겹침.
- 수정 (`PlayerInteractor.cs`, SYS 파일은 수정 안 함): 상호작용 대상이 범위 안에 있거나 대화 중일 때만 `rotateStep`을 0으로 막고, 벗어나면 원래 값으로 복구. 이름으로 찾으므로 없으면 아무 일도 안 함.
- 범위 안에서는 Q 회전도 막힘 (마우스 드래그 · R/F는 동작). 틀어진 각도는 **Shift + Home**으로 초기화.
- 근본 해결: SYS 팀에 카메라 회전 키 변경 요청 권장.
- (11-16) 막는 코드를 `CameraStepBlock.cs`로 분리 → NPC(`PlayerInteractor`)와 문(`DoorInteractable`)이 같이 막아도 원래 값이 꼬이지 않게 막는 쪽을 세어 둠.

## 10. 오프닝 컷신 대사 교체 (11-15)

- 오프닝 대사 파일: `03.Data/Cutscene/opening.json` (컷신이 JSON을 직접 읽음 → 데이터 패킹 불필요)
- 새 대본 `opening-1.json`의 **내용을 `opening.json`에 덮어쓰고**, `opening-1.json`은 삭제.
  - `opening.json`을 지우고 이름을 바꾸지 않은 이유: 컷신 프리팹(`05.Prefab/Cutscene/CutsceneCanvas.prefab`)이 파일 **GUID**로, `CutsceneSetup.cs`가 **경로**로 참조함 → `.meta`(GUID)를 유지해야 연결이 안 끊김.
- 새 구성: 샷 26개 (대사 23 + 타이틀 3: 10년 전 / 현재 / 제1막)

| 구간 | 내용 요약 |
|---|---|
| 10년 전 · A사 지하 연구동 | A사 코어(전용 부품만) → 천재 엔지니어의 범용 코어 → 빚 때문에 총수에게 → 총수 "설계도를 지웠군…" / 아버지 "길드 레이스 최종 보스 안에 있다 · 내가 만든 레이스다" → 아버지 사망, 아들 행방불명 → 길드 레이스가 국가 산업이 됨 |
| 현재 · 도시 외곽 · 고물상 | 고물상과 지하 작업실 → 아버지의 코어(텅 빈 힘) → 나머지 설계도는 최종 보스 안 → 길드 · 지역 1~3 보스 지도 핀 → 총수는 아직 설계도와 아들을 찾는 중 → "가짜 이름과 후드 뒤에, 정체를 숨긴 채로" → "아버지의 코어를 완성하고 복수할 길은, 그것뿐이다" |
| 제1막 | 고물상의 상속자 |

- 수정 방법: 대사는 `"text"`, 타이틀은 `"title"` · `"subtitle"`. 화자가 있으면 `"speaker"` · `"voice"`, 지도 연출은 `"pin"` · `"x"` · `"y"` · `"zoom"` · `"move"`, 타이틀 시간은 `"hold"`(초). 마지막 줄 빼고 끝에 쉼표.

## 11. 경매장 등록직원 (11-15)

**LHM 밖 씬에서도 연결**
- 길드 접수원 · 경매장 NPC 연결 버튼은 LHM 밖 씬(예: LSH `Tester.unity`)에서도 실행됨 (확인 창에 "LHM 밖의 씬" 경고). 나머지 버튼은 그대로 LHM 씬만.
- 다른 팀 씬이므로 **저장 전에 담당자와 확인**.

**이름 · 중복 삭제 · 카메라**
- 이름: "경매 진행자" → **"등록직원"**.
- `[E] 등록직원` 안내가 2개 뜨던 문제: 같은 Speaker Id(또는 같은 역할)의 NpcInteractable이 다른 오브젝트에 또 있으면, 연결할 때 목록을 보여 주고 삭제(Ctrl+Z 가능).
- 클로즈업: NPC 등 뒤에서 보던 카메라 → 등록 데스크 쪽 **앞에서 조금 위**를 보도록 `CloseUpPoint` 자식을 자동 생성 (NPC 앞 2.2m · 키 1.05배 높이에서 가슴 높이를 봄). 다시 실행하면 위치만 다시 맞춤.

**경매 메뉴** (Tester.unity의 LSH `Auction`과 연결, LSH 파일은 수정 안 함 · 이름으로 찾음)

| 선택지 | 동작 |
|---|---|
| 1. 경매 | → 1. 일반 경매 2. 주먹 경매 3. 뒤로 |
| 　· 일반 / 주먹 경매 | 대화를 닫고 경매 시작(`OnStartAuctionButton`) → 모드 선택을 물을 때 자동으로 고름 (`OnSelectNormalMode` / `OnSelectFistMode`) |
| 2. 옵션 | 경매장 판매 옵션 창(`shopPanel`) 열기 → 닫으면 메뉴로 |

- 새 파일 `AuctionBridge.cs`: LSH `Auction`을 리플렉션으로 호출.
- 주의: 모드 자동 선택은 **첫 판만** (이후 판은 LSH UI에서 고름). LSH의 왼쪽 "경매 시작" 버튼도 그대로 있음. 옵션 창은 경매 전에도 열림.

**스프라이트**
- 등록직원 그림이 없던 문제 → `Assets/Sprites/NPC-PC.png`의 `NPC-PC_1` 스프라이트를 잘라 `09.Asset/NPC/auctioneer.png`로 저장 (키 1.6m).
- 적용: 대화 툴 → 연출 · NPC → NPC 스프라이트. 여러 장이 든 시트에서 원하는 스프라이트만 자르는 기능(`spriteName`) 추가.

## 12. 공용 사운드 매니저 (11-15)

대화 툴 → **사운드 → 공용 사운드 매니저**. 프리팹 하나를 씬마다 넣고 그 씬 BGM만 정하는 구조.

- 프리팹: `05.Prefab/Sound/SoundManager.prefab` / 효과음 목록: `03.Data/Sound/SoundLibrary.asset`
- **다른 씬 적용**: 프리팹을 끌어다 놓거나 같은 버튼 → 인스펙터 **"이 씬 BGM"**만 바꾸기.
- 동작
  - 처음 만들어진 매니저 하나만 씬이 바뀌어도 살아남아 실제로 소리를 냄 (DontDestroyOnLoad). 뒤 씬의 매니저는 자기 씬 BGM · 효과음 목록만 넘겨주고 대신 전달만 함 → 그 씬 버튼 이벤트도 그대로 동작.
  - 다음 씬 BGM이 같은 곡이면 **끊지 않고 이어감**, 다른 곡이면 1초 **크로스페이드**.
  - 매니저가 없는 씬에서 코드로 부르면 자동 생성.
  - 효과음 동시 16개 (넘으면 가장 오래된 소리를 끊음). 위치 효과음은 멀수록 작게(최대 25m).
- 코드: `using RealSteel.Sound;` → `SoundManager.Sfx(clip)` · `Sfx("id")` · `SfxAt(clip, 위치)` · `Bgm(clip)` · `StopBgm()`
- 인스펙터 이벤트(버튼 OnClick 등): `PlaySfx(AudioClip)` · `PlaySfxById` · `PlayBgm` · `FadeOutBgm` · `SetBgmVolume` · `SetSfxVolume`
- 효과음 목록: id에 클립 여러 개를 넣으면 무작위 재생, 음높이 범위로 반복감 줄이기.
- 믹서: `Assets/Sound/Master.mixer`의 BGM · SFX 그룹이 있으면 연결만 함 (다른 팀 파일, 수정 안 함).

## 13. 메인 메뉴 설정 ↔ 사운드 매니저 연결 (11-16)

- 설정 > 사운드: **전체 음량 · BGM 음량 · 효과음 음량** 슬라이더 → `MainMenuController` → 사운드 매니저로 전달.
- 음량은 PlayerPrefs에 저장(Heat 슬라이더 키 `Slider_RealSteel ... Volume`) → 모든 씬에 적용.
- 씬에 사운드 매니저가 없어도 실행 중 자동 생성되어 음량이 적용됨.
- "메인 메뉴 씬 (Heat UI)"로 메인 메뉴를 새로 만들어도 BGM · 효과음 슬라이더가 같이 생김.
- 기존 MainMenu 씬: 사운드 버튼을 한 번 눌러 매니저 배치 + 슬라이더 추가 → **Ctrl+S 저장** 필요 (11-16 기준 저장된 씬에는 아직 없음).

## 14. 집 문 → 집 씬 이동 (11-16)

대화 툴 → 연출 · NPC → **집 문 → 집 씬 이동**. 문을 선택하고 누르면(선택이 없으면 SYS가 만든 `집_바깥 문 · 창 (자동)/문`을 찾음) 문 아래 바깥쪽에 `집 입구 ([E] 들어가기)` 오브젝트 생성.

- 가까이 가면 **"[E] 들어가기"**, 멀어지면 사라짐 (반경 1.6m, 선택하면 초록 원으로 표시). E → 씬 이동.
- 대화 시스템이 없는 씬에서도 혼자 동작 (플레이어: SYS `RSSimpleCharacter` → `PlayerInteractor` → "Player" 태그 순으로 찾음).
- 문 앞에서는 E/Q 카메라 회전을 막음. NPC 안내가 떠 있거나 대화 중이면 문은 양보.
- 안내 모양은 NPC 안내를 복사, 없으면 나눔바른고딕으로 새로 만듦.
- LJS 로딩 화면(`LoadingManager`)이 떠 있으면 그걸로 이동, 없으면 바로 이동.
- 이동할 씬: 기본 `SYS/Scenes/Home_Workshop.unity` (인스펙터 "이동할 씬"에 씬 파일을 끌어다 바꿈).
- 주의
  - **Home_Workshop은 Build Settings에 없음** → 에디터 플레이에서만 넘어감, 빌드 전에 등록 필요 (인스펙터에 경고 표시).
  - 입구는 SYS 도구가 다시 만드는 `집_바깥 문 · 창 (자동)` 밖(컨테이너 바로 아래)에 둠 → SYS 도구를 다시 눌러도 안 지워짐.
  - Map_Test는 SYS 씬 → 저장 전에 담당자와 확인.
  - 집 안 → 밖 문은 아직 없음 (집 씬에서 같은 버튼 후 이동할 씬만 바꾸면 됨).
