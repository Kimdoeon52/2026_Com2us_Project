# 나노봇(NanoBot) 절차적 애니메이션 학습 & 제작 가이드

> **기준 구현체**: `Assets/SYS/RS/NanoBoss/` (테스트 씬: `Assets/SYS/Scenes/NanoBoss_Test.unity`)  
> **학습 목표**: `GameObject` 수만 개 없이 수만 개의 입자(알갱이)를 60fps로 제어·렌더링하는 **데이터 지향(DOD) + 절차적 애니메이션(Procedural Animation)** 원리를 이해하고, 직접 나만의 **미니 나노봇(Mini NanoBot)**을 바닥부터 구현한다.

---

## 1. 핵심 설계 철학: 왜 `GameObject`가 없는가?

일반적인 Unity 오브젝트 16,000개를 띄우고 `Update()`마다 `transform.position`을 바꾸면 CPU 오버헤드와 Draw Call 때문에 수 FPS로 추락합니다.  
`RSNanoBoss`는 이를 **3단계 파이프라인**으로 해결합니다.

```
[1. 목표 틀 (Guide / Rig)]        "어디로 가야 하는가?" (보이지 않는 뼈대/타원/곡선/스프라이트 좌표)
          │  (매 프레임 목표 좌표 계산)
          ▼
[2. 시뮬레이션 (Burst Jobs)]      "어떻게 움직이는가?" (2차 감쇠 스프링 + 유체 점성 + 모래 물리)
          │  (NanoBot[] 구조체 배열 갱신 → 48바이트 NanoGpuBot[] 패킹)
          ▼
[3. 렌더링 (GPU Instancing)]      "어떻게 그리는가?" (메시 0개, StructuredBuffer + RenderPrimitives 1회 호출)
```

### 핵심 구조 요약
| 레이어 | 담당 스크립트 | 핵심 역할 |
|---|---|---|
| **개별 입자 데이터** | `RSNanoSwarm.cs` (`struct NanoBot`) | 봇 1개의 위치(`pos`), 속도(`vel`), 모드(`Bound`/`Free`/`Debris`/`Dead`), 소속 가이드(`guide`), 목표 칸(`cell`), 난수 개성(`hash`, `hash2`, `hash3`) 보유 |
| **목표 틀(가이드)** | `RSNanoSwarm.Guides.cs` (`BlobGuide`, `TubeGuide`, `RingGuide`, `KnightGuide`, `HaloGuide`) | 봇이 따라갈 도형 정의. 보스 몸 자체가 아니라 **"봇을 끌어당기는 자석 틀"** |
| **애니메이션 리그** | `RSNanoRig.cs`, `RSNanoLimb.cs`, `RSNanoJoint.cs` | Unity `AnimationClip` 키프레임 + 관절 체인(`Chain`/`Blob`/`Puddle`/`Sprite`/`Swarm`)을 절차적 물리와 결합 |
| **격자 & 할당** | `RSNanoLattice.cs` (`NanoLattice`, `NanoSlotSet`) | 입자들이 한곳에 뭉치거나 구멍 나지 않도록 정사각/타원/테이퍼 격자 슬롯 생성 및 빈자리 메우기 |
| **물리 엔진** | `RSNanoSim.cs` (`NanoGridJob`, `NanoSimJob`, `NanoSandJob`, `NanoUploadJob`) | C# Job System + Burst 컴파일로 수만 개 입자 병렬 연산 |
| **GPU 셰이더** | `NanoBotPixelLit.shader` | 버텍스 버퍼/메시 없이 `SV_VertexID`(0~5)와 `SV_InstanceID`로 사각형 쿼드 생성 + 이웃 비트마스크(`open`)로 가장자리 입체 음영 계산 |

## 2. 반드시 알아야 할 절차적 애니메이션 6대 핵심 기법

### 기법 1. 폭발하지 않는 스프링: 해석적 감쇠 조화 진동자 (`NanoSpring.Step`)

절차적 애니메이션에서 가장 흔히 쓰는 `pos += (target - pos) * speed * dt` (단순 Lerp/지수 감쇠)는 **출렁임(오버슈트/탄성)**이 없고 밋밋합니다.  
반면 순수 오일러 스프링 `vel += (target - pos) * k * dt`은 프레임이 떨어져 `dt`가 커지면 무한대로 발산(폭발)합니다.

`RSNanoSim.cs`의 `NanoSpring.Step()`은 감쇠 조화 진동자 미분방정식의 **정확해(Analytical Solution)**를 사용합니다.

#### 수학적 원리 (`RSNanoSim.cs` L87~126)
* **디자이너 친화적 변환 (`FromFrames`)**: `stiffness`, `damping` 같은 추상적 숫자 대신 **"몇 프레임(1/60초 기준) 만에 도착할지(`response`)"**와 **"얼마나 출렁일지(`bounce` 0~1)"**로 직관적으로 제어합니다 (`SettleK = 4.7f`).
  * `bounce = 0` → 감쇠비 `zeta = 1.0` (임계 감쇠: 튕김 없이 딱 멈춤)
  * `bounce = 1` → 감쇠비 `zeta = 0.2` (부족 감쇠: 젤리처럼 크게 출렁이다 멈춤)

$$\omega = \frac{4.7}{\max(1/60,\ \text{response} / 60)}, \qquad \zeta = 1 - 0.8 \cdot \text{saturate}(\text{bounce})$$

$$\omega_d = \omega \sqrt{1 - \zeta^2}, \qquad e = e^{-\zeta \omega \Delta t}$$

$$x(t+\Delta t) = \text{target} + e \left( x_0 \cos(\omega_d \Delta t) + \frac{v_0 + \zeta \omega x_0}{\omega_d} \sin(\omega_d \Delta t) \right)$$

이 식 덕분에 `dt`가 0.05초로 튀어도 **절대 발산하지 않으며**, 에디터에서 타임라인을 뒤로 감았다 다시 재생해도 **항상 100% 동일한 궤적**을 재현합니다.

### 기법 2. 스파인 히스토리 링 버퍼를 이용한 팔로스루 & 잔상 (`SampleSpine` & `tipLag`)

채찍을 휘두르거나 거대한 칼을 내리칠 때, 손잡이(뿌리)가 움직이고 나서 **칼끝(Tip)이 몇 프레임 늦게 따라오는 잔상**을 만들면 타격감이 극대화됩니다.

#### 동작 방식 (`RSNanoRig.cs` `RecordSpines` & `RSNanoSim.cs` `SampleSpine`)
1. `RSNanoRig`은 매 프레임 모든 `Chain` 부위의 32개(`S = 32`) 관절선 샘플 포인트(위치 `xyz` + 반지름 `w`)를 48프레임(`H = 48`) 길이의 **원형 링 버퍼(`spine`, `spineTime`)**에 기록합니다.
2. `NanoSimJob.ChainTarget()`이 봇을 배치할 때, 뿌리(`u = 0`)부터 끝(`u = 1`)까지의 비율 `u`에 따라 **과거 시점(`when`)**을 다르게 요청합니다.
   ```csharp
   float lagT = L->lag > 0f ? L->lag * u * (0.4f + 0.6f * b->hash2) : 0f;
   SampleSpine(L, u * grow, clock - lagT, out p, out tan, out r);
   ```
   * 뿌리 (`u = 0`): `lagT = 0` → 현재 프레임 위치 추적
   * 끝 (`u = 1`): `lagT = lag` → 예: `13프레임(약 0.22초)` 전의 관절 위치를 추적 (+ 봇 개별 랜덤 `hash2`로 가루처럼 흩어지는 잔상 효과)

### 기법 3. 순방향 사슬(Chain) 각도 지연 물리 (`TubeGuide.ChainStep`)

코드 기반 촉수/채찍(`Whip` 패턴)은 관절 하나하나에 `Rigidbody`와 `HingeJoint`를 달지 않고, **단 12줄의 각도 스프링 루프**로 구현합니다 (`RSNanoSwarm.Guides.cs` L106~122).

1. `K = 16`개의 마디 각도 배열 `ang[0..14]`과 각속도 `angVel[0..14]`를 둡니다.
2. 마디 `0`은 목표 각도(`baseAngleDeg`)를 강한 강성(`stiff * 1.6f`)으로 따라갑니다.
3. 마디 `i`는 바로 앞 마디 `ang[i - 1]`의 각도를 목표로 삼되, **끝으로 갈수록 강성을 25%까지 약화**시킵니다:
   ```csharp
   float k = i == 0 ? stiff * 1.6f : stiff * (1f - 0.75f * i / (K - 2f));
   float c = 2f * Mathf.Sqrt(k) * 0.55f; // 감쇠비 0.55 유지
   ```
4. 구해진 각도를 루트 위치부터 순차 적분(`nodes[i+1] = nodes[i] + (cos, sin) * segLen`)하면 **채찍이 휘감기는 역동적인 S자 곡선**이 탄생합니다.

### 기법 4. 무작위가 아닌 격자 패킹 & 비트 역전 정렬 (`NanoLattice` & `NanoSlotSet`)

수만 개의 봇에 `Random.insideUnitCircle`로 목표를 주면 봇끼리 겹쳐 빈 구멍이 생기고 반짝거리는(Alias) 노이즈가 발생합니다.  
나노봇이 **단단한 기계 덩어리**처럼 보이게 하는 핵심이 `NanoLattice`입니다.

1. **타원 격자 & 비트 역전 정렬 (`EllipseHex` + `SortSpread`)**:
   * 타원 내부를 정사각 격자 좌표로 채운 뒤 반지름 순(안쪽 → 바깥쪽)으로 정렬합니다.
   * **핵심 트릭 (`BitRev`)**: 같은 반지름(고리)에 있는 칸들을 각도 순서대로 놓으면, 보스 체력이 닳아 봇 수가 줄어들 때 **고리가 한쪽 방향(예: 12시~3시)부터 파여 부자연스럽게 보입니다**. 비트 역전(Bit-Reversal) 순서로 섞어 두면 바깥 테두리가 **사방에서 균일하게 깎여 나갑니다**.
2. **구멍 메우기 & 다지기 (`NanoSlotSet.Maintain`)**:
   * 피격(`Hit`)으로 몸통 일부 봇이 떨어져 나가면(`Debris`), 그 슬롯의 `freeAt[k] = now + hitDelay`로 예약해 **잠시 구멍이 뚫린 타격감**을 노출합니다.
   * `hitDelay` 이후에는 가장 바깥쪽(채움 순서 끝 `hi`)에 있는 봇 중 **구멍에 가장 가까운 봇**을 뽑아 빈 구멍(`lo`)으로 이동시킵니다. 이로써 몸집 전체가 자연스럽게 수축합니다.

---

### 기법 5. `bind` (결속): 유체(Fluid) ↔ 기계(Rigid) 실시간 전환

`RSNanoLimb.bind` (0~1) 값 하나로 같은 봇 덩어리가 **흐르는 물/슬라임**이 되기도 하고 **단단한 강철 가시/주먹**이 되기도 합니다 (`RSNanoSim.cs` L299~354).

* **`bind = 0` (유체 상태, `fluid = 1 - bind`)**:
  1. **연속 흐름 (`Flow`)**: 위치 기반 `sin`/`cos` 합성 파동 변위를 목표 좌표에 더해 이웃 봇끼리 같은 방향으로 꿀렁이게 만듭니다.
  2. **점성 (`NanoGridJob` + `CellVelocity`)**: 주변 3×3 격자 셀 내 이웃 봇들의 평균 속도를 구해 내 속도를 섞어 줍니다(Boids/SPH 점성 근사). 흩어지지 않고 **한 덩어리로 흐르는 느낌**의 비결입니다.
  3. **표면 떨림**: `b->edge`(가장자리) 여부를 곱해 안쪽은 안정시키고 표면만 살아 꿈틀거리게 합니다.
* **`bind = 1` (기계 상태)**:
  * 흐름과 점성이 `0`이 되며 각 봇이 격자 슬롯에 칼같이 정렬됩니다.
  * `bind`가 `0 → 1`로 넘어가는 순간 `lockAge`가 기록되어 뿌리(`frac = 0`)부터 끝(`frac = 1`)까지 **빛 물결(`b->flash`)**이 순차적으로 차오르며 "결정화(고정)" 연출을 만듭니다.

### 기법 6. 메시 없는 GPU 렌더링 + 비트마스크 2.5D 입체 조명

`RSNanoSwarm.OnBeginCamera()`는 Unity Mesh도, GameObject도 쓰지 않습니다.

```csharp
Graphics.RenderPrimitives(rp, MeshTopology.Triangles, 6, bots.Length);
```
1. **CPU → GPU 전송 (`NanoGpuBot`, 48바이트)**: 위치(`pos`), 크기(`size`), 번쩍임(`flash`), 발광(`glow`), 테두리(`rim`), **이웃 비트마스크(`open`)**, 색상(`color`)을 `GraphicsBuffer(Target.Structured)`에 `SetData`로 한 번에 업로드합니다.
2. **이웃 비트마스크를 이용한 입체 노멀 계산 (`NanoUploadJob` & `NanoBotPixelLit.shader`)**:
   * `NanoUploadJob`이 2D 비트맵(`occBits`)에 판 위의 모든 봇을 찍은 뒤, 각 봇의 위(`1`), 아래(`2`), 왼(`4`), 오른(`8`) 칸이 비었는지 검사해 `open` 4비트에 기록합니다.
   * 셰이더의 `BuildBotVertex()`에서 이 4비트를 읽어 법선 벡터를 계산합니다:
     ```hlsl
     float2 e = float2(rt - lf, up - dn);
     o.normalWS = normalize(float3(e * _EdgeTilt, -1.0));
     o.shade = (half)(up * _TopLight - dn * _BottomDark);
     ```
   * 결과: **2D 픽셀 알갱이 덩어리인데도 위쪽 테두리는 밝고 아래쪽은 그림자가 지며, URP 메인 라이트/그림자/간접광까지 받는 입체 덩어리**로 렌더링됩니다.

## 3. 실전 미니 나노봇(Mini NanoBot) 만들기 — 5단계 실습 로드맵

직접 이 구조를 체득하려면 거대한 보스 전체를 한 번에 베끼기보다, 아래 **5단계 미니 프로젝트**를 순서대로 직접 코딩해 보는 것이 가장 효과적입니다.

### Step 1. 단일 드로우 콜 1,000개 입자 렌더링 (뼈대 세우기)
* **목표**: `MonoBehaviour`에서 구조체 배열 `MiniBot[]`과 `GraphicsBuffer`를 만들어 `Graphics.RenderPrimitives`로 화면에 픽셀 사각형 1,000개 그리기.
* **핵심 구현**:
  1. GPU 전달용 `[StructLayout(LayoutKind.Sequential)] struct GpuBot` 정의 (위치 `Vector3` + 크기 `float` + 패킹된 색상 `uint`).
  2. `RenderPipelineManager.beginCameraRendering` 구독 후 `GraphicsBuffer(GraphicsBuffer.Target.Structured, count, stride)` 업로드.
  3. 셰이더에서 `SV_VertexID % 6`으로 사각형 2삼각형(`kCorners[6]`) 생성, `SV_InstanceID`로 `_Bots[instanceID]` 읽기.
* **체크포인트**: 씬에 오브젝트는 단 1개인데 화면에 작은 사각형 1,000개가 0.1ms 만에 그려지는가?

### Step 2. 해석적 감쇠 스프링 붙이기 (`NanoSpring`)
* **목표**: `NanoSpring.Step`과 `FromFrames`를 구현하여, 모든 입자가 마우스 커서/타겟 주변을 향해 탄성 있게 날아오게 만들기.
* **핵심 실험**:
  * 인스펙터 슬라이더 2개(`response`: 1~60 프레임, `bounce`: 0~1)를 만들어 플레이 중에 조절해 보세요.
  * `bounce = 0`일 때의 묵직한 기계적 움직임과 `bounce = 0.7`일 때의 말랑거리는 젤리 탄성 차이를 직접 눈으로 체감합니다.

### Step 3. 격자 배치 + 개성(`hash`) + 유체 흐름(`Flow`)
* **목표**: 무작위 점이 아닌, 꽉 찬 **타원형 나노봇 덩어리** 만들기.
* **핵심 구현**:
  1. 각 봇 초기화 시 `hash = Random.value` 부여 (봇마다 떨림 위상·잔상 지연·색상 미세 차이 결정).
  2. 봇 `k`에게 타원 격자 좌표 `(x, y)` 할당 (`NanoLattice.EllipseHex` 참고 — 처음엔 피보나치 나선 `r = sqrt((k + 0.5f) / N)`, `θ = k * 2.39996f`로 시작하면 5줄로 고른 원반을 만들 수 있습니다).
  3. 목표 위치에 `Flow(pos, time) * (1 - bind)` 사인파를 더하고, `bind` 슬라이더를 `0 ↔ 1`로 움직여 **유체에서 고체로 전환되는 순간**을 확인합니다.

### Step 4. 관절 체인(Whip/Tentacle) + 히스토리 잔상(`tipLag`) 구현
* **목표**: 타겟을 휘두를 때 16마디 꼬리/촉수가 유연하게 뒤따라오며 잔상을 남기게 만들기.
* **핵심 구현**:
  1. 마디 16개 각도 `ang[15]`를 앞 마디를 추종하는 약한 스프링으로 회전 (`TubeGuide.ChainStep`).
  2. 최근 `H = 48`프레임 동안의 `S = 32`개 스파인 좌표를 저장하는 링 버퍼 구현.
  3. 봇의 길이 비율 `u` (0~1)에 따라 과거 프레임 `clock - tipLag * u`의 좌표를 보간해서 타겟으로 지정.
* **체크포인트**: 빠르게 휘둘렀을 때 끝부분 봇들이 허공에 궤적을 그리며 따라오는 **아크(Arc) 잔상**이 생기는가?

### Step 5. 상태 전환 (`Bound ↔ Free ↔ Debris`) 및 피격 구현
* **목표**: 보스의 "탄환 발사(`Free`) → 복귀(`Bound`)" 및 "피격 탈락(`Debris`) → 바닥 쌓임" 사이클 완성하기.
* **핵심 구현**:
  1. `enum BotMode { Bound, Free, Debris }` 도입.
  2. 특정 키를 누르면 덩어리에서 50개를 뽑아(`Free`) 목표 방향으로 발사(`vel`), `life`가 끝나면 다시 `Bound` 모드로 바꿔 스프링으로 본체에 재합류시킵니다.
  3. 마우스 클릭 위치 반경 `R` 안의 `Bound` 봇들을 `Debris`로 전환하고 바깥으로 튕겨(`vel = dir * impulse`) 중력(`gravity`)으로 바닥(`floorY`)에 떨어뜨립니다.
  4. 여유가 되면 `NanoUploadJob`의 `open` 비트마스크 라이팅을 셰이더에 추가해 입체감을 완성합니다.

아래 두 파일만 학습용 테스트 폴더에 넣고 빈 오브젝트에 `MiniNanoSwarm`을 붙인 뒤 `shader` 슬롯에 셰이더를 연결하면, 외부 의존성 없이 **해석적 스프링 + 피보나치 타원 격자 + `bind`(유체↔고체) 전환 + GPU 인스턴싱**을 즉시 실행하며 코드 한 줄씩 바꿔 볼 수 있습니다.

```hlsl
Shader "Learning/MiniNanoBot"
{
    SubShader
    {
        Tags { "RenderType" = "Opaque" "RenderPipeline" = "UniversalPipeline" }
        Pass
        {
            Cull Off
            HLSLPROGRAM
            #pragma target 4.5
            #pragma vertex Vert
            #pragma fragment Frag
            #include "Packages/com.unity.render-pipelines.universal/ShaderLibrary/Core.hlsl"

            struct MiniGpuBot
            {
                float3 pos;
                float  size;
                uint   color;
                float3 pad;
            };
            StructuredBuffer<MiniGpuBot> _Bots;

            static const float2 kCorners[6] = {
                float2(0,0), float2(1,0), float2(1,1),
                float2(0,0), float2(1,1), float2(0,1)
            };

            struct Varyings {
                float4 posCS : SV_POSITION;
                nointerpolation half4 col : TEXCOORD0;
            };

            Varyings Vert(uint vid : SV_VertexID, uint iid : SV_InstanceID)
            {
                MiniGpuBot b = _Bots[iid];
                float2 q = (kCorners[vid % 6] - 0.5) * b.size;
                Varyings o;
                o.posCS = TransformWorldToHClip(b.pos + float3(q.x, q.y, 0));
                o.col = half4(b.color & 0xFF, (b.color >> 8) & 0xFF, (b.color >> 16) & 0xFF, 255) / 255.0;
                return o;
            }

            half4 Frag(Varyings i) : SV_Target { return i.col; }
            ENDHLSL
        }
    }
}
```

### 2) `MiniNanoSwarm.cs`
```csharp
using System.Runtime.InteropServices;
using Unity.Mathematics;
using UnityEngine;
using UnityEngine.Rendering;

public class MiniNanoSwarm : MonoBehaviour
{
    [Range(100, 5000)] public int botCount = 1200;
    [Range(1f, 60f)] public float responseFrames = 14f; // 도착 프레임 (작을수록 빠름)
    [Range(0f, 1f)]  public float bounce = 0.4f;        // 출렁임 (0=딱 멈춤, 1=젤리)
    [Range(0f, 1f)]  public float bind = 0.5f;          // 0=유체 흐름, 1=단단한 격자
    public float radius = 2.0f;
    public float botSize = 0.08f;
    public Shader shader;

    struct Bot { public float3 pos, vel; public float2 slot; public float hash; }

    [StructLayout(LayoutKind.Sequential)]
    struct GpuBot { public float3 pos; public float size; public uint color; public float3 pad; }

    Bot[] _bots;
    GpuBot[] _gpu;
    GraphicsBuffer _buffer;
    Material _mat;
    MaterialPropertyBlock _mpb;

    void OnEnable()
    {
        _bots = new Bot[botCount];
        _gpu = new GpuBot[botCount];
        for (int i = 0; i < botCount; i++)
        {
            float a = i * 2.39996f;
            float r = math.sqrt((i + 0.5f) / botCount);
            _bots[i] = new Bot
            {
                pos = (float3)transform.position,
                slot = new float2(math.cos(a) * r, math.sin(a) * r),
                hash = (i * 0.618034f) % 1f
            };
        }
        _buffer = new GraphicsBuffer(GraphicsBuffer.Target.Structured, botCount, Marshal.SizeOf<GpuBot>());
        if (shader) _mat = new Material(shader);
        _mpb = new MaterialPropertyBlock();
        RenderPipelineManager.beginCameraRendering += OnRender;
    }

    void OnDisable()
    {
        RenderPipelineManager.beginCameraRendering -= OnRender;
        _buffer?.Release();
        if (_mat) DestroyImmediate(_mat);
    }

    void Update()
    {
        float dt = Mathf.Min(Time.deltaTime, 0.05f);
        float t = Time.time;

        // 1. 프레임 기반 느낌 -> 물리 계수 변환
        float omega = 4.7f / Mathf.Max(1f / 60f, responseFrames / 60f);
        float zeta = 1f - 0.8f * Mathf.Clamp01(bounce);
        float3 center = transform.position;

        for (int i = 0; i < _bots.Length; i++)
        {
            ref Bot b = ref _bots[i];
            float3 tgt = center + new float3(b.slot * radius, 0f);

            // 2. 유체(bind < 1)일 때 연속 흐름(Flow) 추가
            float fluid = 1f - bind;
            if (fluid > 0.01f)
            {
                float fx = math.sin(tgt.y * 1.8f + t * 2.2f) * 0.25f;
                float fy = math.cos(tgt.x * 1.6f - t * 1.9f) * 0.25f;
                tgt += new float3(fx, fy, 0f) * fluid;
            }

            // 3. 해석적 감쇠 스프링 스텝
            StepSpring(ref b.pos, ref b.vel, tgt, omega, zeta, dt);

            byte shade = (byte)(120 + b.hash * 110);
            _gpu[i] = new GpuBot
            {
                pos = b.pos,
                size = botSize,
                color = (uint)(shade | ((shade + 20) << 8) | (255u << 16) | (255u << 24))
            };
        }
        _buffer.SetData(_gpu);
    }

    static void StepSpring(ref float3 pos, ref float3 vel, float3 target, float omega, float zeta, float dt)
    {
        omega = math.max(0.05f, omega);
        zeta = math.clamp(zeta, 0.02f, 0.999f);
        float3 x0 = pos - target;
        float3 v0 = vel;
        float zw = zeta * omega;
        float e = math.exp(-zw * dt);
        float wd = omega * math.sqrt(1f - zeta * zeta);
        if (wd < 1e-3f)
        {
            float3 c1 = v0 + omega * x0;
            pos = target + e * (x0 + c1 * dt);
            vel = e * (v0 - omega * c1 * dt);
            return;
        }
        math.sincos(wd * dt, out float s, out float c);
        pos = target + e * (x0 * c + (v0 + zw * x0) / wd * s);
        vel = e * (v0 * c - (omega * omega * x0 + zw * v0) / wd * s);
    }

    void OnRender(ScriptableRenderContext ctx, Camera cam)
    {
        if (!_mat || _buffer == null) return;
        if (cam.cameraType == CameraType.Preview || cam.cameraType == CameraType.Reflection) return;
        _mpb.SetBuffer("_Bots", _buffer);
        var rp = new RenderParams(_mat)
        {
            camera = cam,
            worldBounds = new Bounds(transform.position, Vector3.one * 50f),
            matProps = _mpb
        };
        Graphics.RenderPrimitives(rp, MeshTopology.Triangles, 6, _bots.Length);
    }
}
```
