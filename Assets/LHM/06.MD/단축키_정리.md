## 1. 필드 (고물상 · 집 · 길드 · 경매장)

| 키 | 기능 | 담당 |
|---|---|---|
| WASD / 방향키 | 이동 | SYS `RSSimpleCharacter` |
| Shift (누름) | 달리기 | SYS |
| Q / E | 카메라 45° 회전 (NPC · 문 앞, 대화 중에는 꺼짐) | SYS (LHM `CameraStepBlock`이 막음) |
| R / F (누름) | 카메라 기울이기 | SYS |
| + / - · 휠 | 줌 | SYS |
| 우클릭 드래그 | 카메라 돌리기 | SYS |
| Shift + Home | 카메라 초기화 | SYS |
| E | NPC · 기계와 상호작용 / 문 들어가기 · 나가기 / 고철 뒤지기 | LHM `PlayerInteractor` · `DoorInteractable`, KDU `ScrapInteractor` |
| Tab | 인벤토리 (Esc 닫기) | KDU `InventoryToggle` |
| C / K | 제작창 / 상점창 | YJW `CraftingUIManager` |
| V | 스킬창 (Esc 닫기) | KDU `SkillWindowView` |
| M / O / Shift + R | 지도 / 달력 / 랭킹 | LJS `SystemUiOnOffManager` |
| Shift + S | 골드 수동 저장 | LSH `GlobalGold` |
| Space | 고철 미니게임 타이밍 | KDU `TimingBarMinigame` |
| F10 | 도움말 · 튜토리얼 다시 보기 | LHM `TutorialDirector` |
| Home | 단축키 안내 (Home · Esc 닫기) | LHM `ShortcutHelpOverlay` |

- 대화 · UI가 열려 있는 동안은 이동 · Tab · C · K가 잠긴다 (`FieldInputBridge`). 고물상 상점 창이 열린 동안은 잠그지 않음

## 2. 대화

| 키 | 기능 |
|---|---|
| Space · Enter · 좌클릭 | 다음 줄 / 글자 즉시 완성 |
| Esc | 스킵 (안 읽은 대사가 있으면 한 번 더 확인) |
| Ctrl (누름) | 읽은 대사 빨리감기 |
| Tab | 오토 |
| L | 백로그 (↑↓ · PgUp/PgDn · 휠로 스크롤, L · Esc 닫기) |
| LOG · AUTO · SKIP 클릭 | 대화창 오른쪽 버튼 (위 L · Tab · Esc와 같음) |

- 대화 시작 0.25초, 줄마다 0.12초는 입력을 무시 (연타 방지)

## 3. 선택 화면 (NPC 선택지 · 보스 레이스 · 난이도 · 시즌 전화)

| 키 | 기능 |
|---|---|
| 1 ~ 9 | NPC 선택지 바로 고르기 (번호가 붙은 선택지) |
| W/S · ↑↓ | 선택지 · 난이도 이동 |
| A/D · ←→ | 보스(지역) 카드 이동 |
| E · Space · Enter | 결정 |
| Esc | 나가기 · 뒤로 · 창 닫기 |
| Z | 시즌 시작 전화 받기 |
| Enter · Z · E / Esc | 예 · 아니요 창 결정 / 아니요 |

## 4. 튜토리얼 · 컷신 · 메인 메뉴

| 화면 | 키 |
|---|---|
| 튜토리얼 창 | ← → (A/D) 이전 · 다음, Space · Enter · E 다음, Esc 닫기. **열린 동안 게임 정지** |
| 도움말 목록 (F10) | ↑↓ (W/S) 고르기, Enter · E · Space 보기, Esc 닫기 |
| 오프닝 컷신 | Space · Enter · 클릭 다음 (자동 진행), Esc 두 번 건너뛰기 |
| 메인 메뉴 | 스플래시에서 아무 키, Esc 종료 확인 |

## 5. 경매장 (LSH)

| 키 | 기능 |
|---|---|
| E (등록직원 앞) | 1. 경매 (일반 · 주먹) 2. 옵션 3. 대화하기 4. 나가기 |
| Space · 좌클릭 | 경매 진행 넘기기 (버튼 위 클릭 제외) |
| Esc | 수리 창 닫기 |

## 6. 전투 (NYH, 사이드뷰)

| 키 | 기능 |
|---|---|
| ← / → | 이동 (같은 방향 두 번 = 대시) |
| ↑ | 점프 |
| Space | 회피 |
| D | 기본 공격 |
| Q / W (누름 = 차지) | 왼팔 / 오른팔 스킬 |
| E / R | 왼다리 / 오른다리 스킬 |

## 8. 겹치는 키 (2026-11-16 확인)

| # | 키 | 겹치는 기능 | 영향 | 권장 |
|---|---|---|---|---|
| 1 | **F1** | LSH UI 보기 (항상) ↔ LHM 패배 기록 · LJS 씬 전환 · KKH 보스 테스트 | F1 한 번에 여러 개가 같이 실행. UI 보기 창은 **배포 빌드에도 생김** | LSH: 개발 빌드 전용으로 + Shift+F1 등으로 이동 |
| 2 | **F6** | KDU 파츠 지급 창 (항상) ↔ LHM 대화 세이브 저장 | 테스트 씬에서 둘 다 실행 | LHM 테스트 키를 Shift+F6으로 옮기는 안 |
| 3 | **F10** | 튜토리얼 도움말 ↔ LHM 풀스크린 대사 테스트 | DialogueTest 계열 씬에서 둘 다 실행 | LHM 테스트 키를 Shift+F10으로 옮기는 안 |
| 4 | F9 | 제작 테스트 재료 ↔ LHM 순위 구간 테스트 | 두 기능이 한 씬에 같이 있을 때만 | 같은 씬에 두지 않음 (현재는 따로 있음) |
| 5 | 1 ~ 5 | NPC 선택지 번호 ↔ LHM 다음 토벌 난이도 테스트 | 테스트 프리팹 씬에서 선택지를 숫자로 고르면 난이도도 바뀜 | 테스트 키를 선택지가 열린 동안 무시하는 안 |
| 6 | 키패드 7 / 8 / 9 | NYH 프레임 정지 ↔ KKH 호이루 기믹 테스트 | 전투 테스트 씬에 둘 다 있으면 같이 실행 | 전투 팀끼리 확인 |
| 7 | V | KDU 스킬창 ↔ LHM 연출 테스트(페이드 인) · KKH 기믹 테스트 | 테스트 씬에서만 | 낮음 |
| 8 | Tab · C · K · E | 인벤토리 · 제작 · 상점 · 카메라 회전 ↔ 대화 | **해결됨** — 대화 중 잠금 · NPC 앞 카메라 회전 막기 | — |

- 참고: NYH `FrameStepper` 파일 위 설명은 F2/F3/F4라고 되어 있지만 실제 키는 키패드 7/8/9
- 다른 팀 파일은 수정하지 않았다. 1 · 6은 담당 팀 확인 필요, 2 · 3 · 5는 LHM 쪽에서 바꿀 수 있음
