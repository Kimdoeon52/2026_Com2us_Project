# 대화 시스템 · NPC 프리팹화

> 개정 2026-11-22 — 11-19 설계 초안을 실제 결정 기준으로 다시 씀
> 목표: SYS `MAP_*` 프리팹처럼 **수정은 프리팹에서만** 하고, 씬을 복사해 여러 벌이 생기는 일을 막는다
> 작성 규칙: 스크립트 설명은 md에만, `.cs`에는 주석 없음

---

## 1. 결정 사항 (11-22)

| 항목 | 결정 |
|---|---|
| 배치 | LHM은 **프리팹까지만** 만든다. 정식 씬(`Scenes/MainScene/Main_*`) 배치는 **씬 담당자**가 한다 |
| 시스템 개수 | 씬마다 대화 시스템 1개. 같은 씬에 2개면 나중 것이 스스로 지워짐 (DontDestroyOnLoad 안 씀) |
| 선택지 데이터화 (`NpcDefinition` SO) | **다음 단계로 미룸** (이번엔 기존 컴포넌트를 그대로 묶기만) |
| 복사본 씬 (`Copys_1116` 등) | 빌드용이라 그대로 둠. 프리팹을 만들 때 NPC · 문 값을 읽어 오는 원본으로만 씀 |

## 2. 규칙

- 수정은 **프리팹 모드**에서. 씬에서 바꿔도 되는 건 위치(Transform)뿐
- SYS 맵 프리팹(`MAP_*`) 파일은 고치지 않음. NPC는 SYS가 정한 방식대로 맵의 `SLOT_` **자식으로** 넣음 → `RSPropSlot`이 SYS `임시_` 모형을 자동으로 끔 (씬 안 오버라이드라 SYS 파일은 그대로)
- NPC 프리팹에는 **겉모습까지** 들어 있음 (복사본 씬에서 맞춘 최신 스프라이트 · 모형 · 클로즈업 점)
- 프리팹 밖(플레이어 · 카메라 · 상점 창 · 고철 상호작용 · 인벤토리 단축키)은 실행할 때 코드가 찾음 → **인스펙터 연결 0개**

## 3. 프리팹 구성

```
LHM/05.Prefab/
├ Dialogue/DialogueSystem.prefab        필드 씬마다 1개 (대화 · 선택지 · 클로즈업 · 보스 레이스 · 난이도 · 시즌 전화 · 이벤트 큐 · 말풍선)
├ Dialogue/DialogueSystem_Test.prefab   Variant — 테스트 키 · 관중 · 바크 테스트 (LHM 테스트 씬 전용)
├ NPC/                                  복사본 씬 오브젝트를 겉모습째 복사 (NpcInteractable + 모형/스프라이트 + CloseUpPoint)
│   NPC_Receptionist   ← League_Lobby  SLOT_NPC_접수원     → MAP_Lobby의 SLOT_NPC_접수원 안
│   NPC_Auctioneer     ← Auction       SLOT_NPC_등록직원   → MAP_Auction의 SLOT_NPC_등록직원 안 (auctioneer.png)
│   NPC_Workbench      ← Home_Workshop SLOT_Workbench_작업대 → MAP_Home의 SLOT_Workbench_작업대 안
│   NPC_Compressor     ← Map_Test      압축기 (고물상 아저씨 역할을 기계가 대신함)
├ Door/Door_Base.prefab                 DoorInteractable (문 → 씬 이동)
└ Scene/                                맵에 자리(SLOT)가 없는 것 묶음 — SYS MAP_*와 같은 좌표
    LHM_Lobby      길드 출구
    LHM_Home       집 출구
    LHM_JunkShop   압축기 + 집 입구   (MAP_고철장에 압축기가 없음)
    (경매장은 맵 밖에 둘 것이 없어 묶음 없음)
```

- 대사 · 선택지 · 반경 · 이미지를 고치려면 `NPC_*` 프리팹 하나만 열면 모든 씬에 반영
- 고물상 아저씨 NPC(`junkdealer`)는 없어짐 — 압축기가 판매 역할. 예전 `Dialogue/NPC_junkdealer` · `NPC_receptionist` 프리팹은 옛 테스트용(구버전 이미지), 어디에서도 참조 안 함
- 튜토리얼 화면 · 전투 기록(`BossProgressStore`) · 전투 난이도 글자 · 사운드 매니저는 실행 중 자동 생성이라 배치 필요 없음

## 4. 씬 담당자 배치 안내

**자동**: 정식 씬을 열고 대화 툴 → 프리팹 → **씬에 대화 · NPC 배치** (씬의 `MAP_*`를 보고 알아서 놓음, Ctrl+Z 가능)

**직접 놓을 때**:

| 정식 씬 | 놓을 것 |
|---|---|
| `Main_League_Lobby` | `DialogueSystem` (Hierarchy 맨 위) · `NPC_Receptionist` → `MAP_Lobby/…/SLOT_NPC_접수원` 자식, 위치 0 · `LHM_Lobby` → 맵과 같은 위치 |
| `Main_Auction_Hall` | `DialogueSystem` · `NPC_Auctioneer` → `SLOT_NPC_등록직원` 자식, 위치 0 |
| `Main_Home_Workshop` | `DialogueSystem` · `NPC_Workbench` → `SLOT_Workbench_작업대` 자식, 위치 0 · `LHM_Home` → 맵과 같은 위치 |
| `Main_Junk_Shop` | `DialogueSystem` · `LHM_JunkShop` → 맵과 같은 위치 |

- 인스펙터에서 채울 칸 없음. SLOT 자식으로 넣으면 SYS 임시 모형이 저절로 꺼짐 (안 꺼지면 SLOT 선택 후 다시 켜기)
- 씬에 필요한 것: 플레이어(SYS `TestCharacter` — `RSSimpleCharacter`로 찾음), EventSystem(클릭용), LJS `TimeSystemManager`(시간 정지 · 00시)
- 문은 정식 씬끼리 연결됨 → 빌드에서 넘어가려면 **Build Settings에 Main 씬 등록 필요** (지금 빌드는 Copys 씬 기준이라 에디터에서만 넘어감)
- Play 시 콘솔에 `[SceneBinder] … 찾지 못했습니다`가 나오면 그 대상을 Binder 칸에 직접 넣으면 됨

## 5. 바뀐 코드 (11-22)

| 파일 | 내용 |
|---|---|
| `Dialogue/Core/DialogueSceneBinder.cs` | 칸이 비면 실행 중 자동 탐색 (예전 대화 툴 "씬 연결" 로직을 런타임으로 옮김): 플레이어 = `RSSimpleCharacter` → `Player` 태그, 카메라 = 그 캐릭터의 `cam` → 가장 앞 카메라, 상점 창 = YJW `CraftingUIManager.shopWindow` → `ShopWindow` 이름, 이동 · 고철 상호작용 · 안내 · UI 단축키(`InventoryToggle` · `CraftingUIManager`)는 이름으로. 같은 씬에 Binder가 이미 있으면 자기 오브젝트를 끄고 지움 (실행 순서 -200이라 다른 컴포넌트 Awake 전) |
| `Dialogue/Editor/ScenePrefabBuilder.cs` (새) | 대화 툴 → 프리팹 → **씬용 프리팹 만들기**: Copys_1116 씬 4개의 `NpcInteractable` 오브젝트를 **자식째 복사**해 NPC 프리팹 생성 (`RSPropSlot` · 자동 생성 메시 자식은 뺌, 크기는 원본 그대로). 맵 SLOT이 없는 압축기와 문은 월드 위치로 묶음 프리팹에. 문 이동 씬은 Copys → Main으로 바꿔 적음. `DialogueSystem.prefab`에 빠진 대사 풀 JSON 추가. **이미 있는 프리팹은 건드리지 않음** — 다시 만들려면 지우고 실행. **씬에 대화 · NPC 배치**: 열린 씬의 `MAP_*` 프리팹을 찾아 대화 시스템 · SLOT 안 NPC · 묶음을 놓음 |
| `Dialogue/Editor/DialogueToolWindow.cs` | 프리팹 묶음 정리: "프리팹 만들기 (DialogueTest 기준)" 삭제(옛 테스트 씬으로 최신 프리팹을 덮어써서), "씬 연결 다시 실행" 삭제(자동 탐색으로 대체), "씬에 프리팹 배치 (LHM 테스트 씬용)"을 새 배치 도구로 교체 (예전 것은 구버전 NPC를 플레이어 옆에 세웠음) |

## 7. 남은 위험

| 위험 | 대응 |
|---|---|
| SYS가 맵 SLOT 위치를 옮김 | SLOT 안 NPC는 같이 따라감. 묶음(압축기 · 문)만 직접 옮김 |
| 테스트 씬에 `MAP_*`를 놓으면 "2 audio listeners" 경고 무한 출력 | `MAP_Lobby` · `MAP_Auction` · `MAP_Home` 안에 카메라 + AudioListener가 있음 → 새 씬 기본 `Main Camera`를 지움 (정식 씬은 해당 없음) |
| SYS가 SLOT 이름을 바꿈 | `ScenePrefabBuilder`의 SLOT 이름 표를 같이 고침 (배치 도구가 이름으로 찾음) |
| 복사본 씬에서 이미지를 또 바꿈 | NPC 프리팹은 복사본이라 자동 반영 안 됨 → 앞으로 이미지는 `NPC_*` 프리팹에서 고침 (또는 그 NPC 프리팹을 지우고 빌더 재실행) |
| 정식 씬에 플레이어가 둘 이상 | Binder가 켜져 있는 첫 `RSSimpleCharacter`를 씀 → 다르면 Binder 칸에 직접 |
| 묶음을 지우고 다시 만들면 씬에 놓인 인스턴스의 위치 수정이 끊길 수 있음 | 한 번 만든 뒤엔 프리팹 모드에서 고치고, 빌더는 없는 것만 만들 때 사용 |
