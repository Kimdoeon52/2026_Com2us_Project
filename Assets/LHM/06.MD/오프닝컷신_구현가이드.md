## 1. 무엇을 만들었나

| 연출 | 내용 |
|---|---|
| 타이틀 카드 | 화면 가운데 큰 글씨 + 노란 선 + 부제. 페이드 인 → 유지 → 페이드 아웃 |
| 지도 카메라 | 지도 한 장 위에서 지정한 지점으로 이동·확대. 지명 핀(노란 마름모 + 이름표) |
| 내레이션 자막 | 화면 아래 타자기 효과. 화자 이름이 있으면 노란 이름 + 글자 사운드 |
| 진행 | 자동 진행 (유지 시간 + 글자 수 비례). Space / Enter / 클릭으로 즉시 완성 → 다음 |
| 건너뛰기 | Esc 한 번 → "한 번 더 누르면 건너뜁니다" 2초 표시, 그 안에 다시 Esc → 종료 |

기존 대화 시스템과 맞춘 규칙

- 열려 있는 동안 **UI 스택에 등록** → 인게임 시간 정지, 입력은 대화 상태 (기획서 xv.2)
- 시작 0.25초, 컷마다 0.12초 입력 무시 (기획서 xiv.2)
- 화자별 글자 사운드는 `DialogueVoice` 재사용. 내레이션(화자 없음)은 무음
- 대화 시스템(`DialogueManager`)이 없는 씬에서도 동작한다. 입력 상태 관리가 없으면 키보드를 직접 읽음

## 3. 만들기 · 확인

1. `Tools > Dialogue > 대화 툴 열기` → **컷신** → `오프닝 컷신 (프리팹 + 테스트 씬)` 실행
2. `OpeningCutscene` 씬이 열리면 Play
3. 확인 표

| # | 확인 | 기대 |
|---|---|---|
| 1 | 시작 | 검은 화면에서 페이드 인, "10년 전 / A사 지하 연구동" |
| 2 | 지도 이동 | A사 본사로 2초간 확대 이동, 핀 표시. 다음 두 줄 동안 핀 유지 |
| 3 | 화자 대사 | "총수", "아버지" 이름이 노란색, 글자 사운드 음색이 서로 다름 |
| 4 | Space | 글자가 나오는 중 → 즉시 완성, 완성 상태 → 다음 컷. 연타해도 한 컷씩 |
| 5 | 자동 진행 | 손대지 않으면 문장 길이에 맞춰 넘어감. 오른쪽 아래 마름모 깜빡임 |
| 6 | Esc 한 번 | 오른쪽 위 안내, 2초 뒤 사라지고 계속 재생 |
| 7 | Esc 두 번 | 0.4초 페이드 후 종료 |
| 8 | 끝 | "제1막 / 고물상의 상속자" 후 페이드 아웃, 콘솔 `[Cutscene] 'opening' 끝` |

- 다시 보기: Play 중 `CutsceneCanvas` 컴포넌트 메뉴(⋮) → `처음부터 다시 재생 (Play 중)`
- 본 기록 지우기: 같은 메뉴 → `본 기록 지우기`

## 4. 시나리오 수정 (`opening.json`)

컷 하나 = `shots` 배열의 항목 하나. 필요한 칸만 적는다.

| 칸 | 의미 | 비우면 |
|---|---|---|
| `title`, `subtitle` | 타이틀 카드 | 타이틀 없음 |
| `text` | 내레이션 자막 | 자막 없음 |
| `speaker` | 화면에 보이는 화자 이름 | 내레이션 (이름 없음, 무음) |
| `voice` | 글자 사운드용 화자 ID (`DialogueVoice` 목록) | 기본 음색 |
| `x`, `y` | 지도 좌표 0~1 (**왼쪽 위가 0, 0**) | — |
| `zoom` | 카메라 확대 (1 = 지도 전체, 최대 4) | 카메라 그대로 |
| `pin` | 지명 핀 이름 | 이전 핀 유지 (카메라를 옮기면 사라짐) |
| `move` | 카메라 이동 시간(초) | 1.5 |
| `hold` | 다 나온 뒤 유지 시간(초) | 2 (자막은 + 글자당 0.04) |

```json
{ "pin": "고물상", "x": 0.22, "y": 0.72, "zoom": 2.4, "move": 2.0,
  "text": "남은 것은 낡은 고물상 하나와, 아무도 열지 못한 작업실 하나." }
```

- 카메라만 움직이는 컷: `text`·`title` 없이 `zoom`만 → 이동이 끝나고 `hold`만큼 기다림
- `title`과 `text`를 한 컷에 같이 쓰면 타이틀 뒤 자막이 이어 나온다 (검사 경고)
- 저장 후 Play하면 바로 반영된다 (프리팹을 다시 만들 필요 없음)

## 5. 실제 그림으로 바꾸기

- `09.Asset/Cutscene/opening_map_placeholder.png`를 **같은 이름으로 덮어쓰면** 프리팹 수정 없이 반영된다. 툴을 다시 실행해도 덮어쓰지 않는다
- 다른 비율의 그림도 화면을 덮도록 맞춰지지만(Envelope), 16:9가 아니면 가장자리가 잘린다. 좌표는 그림 기준 0~1이라 그대로 쓸 수 있다
- 지점 위치가 바뀌면 `opening.json`의 `x`, `y`만 고친다

## 6. 게임에 연결하기

`CutscenePlayer` 인스펙터

| 칸 | 용도 |
|---|---|
| `Play On Start` | 씬 시작 시 자동 재생 (기본 켜짐) |
| `Play Only Once` | 한 번 본 뒤에는 재생하지 않음 (PlayerPrefs `cutscene.seen.opening`) |
| `Next Scene Name` | 끝나면 이동할 씬. Build Settings에 없으면 이동하지 않고 에러 |

연결 방법 두 가지 (팀과 결정)

| 방법 | 설정 |
|---|---|
| 전용 씬 | 타이틀 → `OpeningCutscene` → 필드 씬. `Play Only Once` 켜고 `Next Scene Name`에 필드 씬 |
| 필드 씬에 배치 | 필드 씬에 프리팹을 놓고 `Play Only Once` 켬. 끝나면 페이드 아웃으로 필드가 보임 |

코드에서 직접 재생: `cutscenePlayer.Play()`, 끝 알림: `cutscenePlayer.Finished += …`

## 7. 알려진 제한 · 다음 할 일

| 항목 | 내용 |
|---|---|
| 확인 범위 | 컴파일만 확인. 화면 배치, 폰트, 실제 입력은 Play 확인 필요 |
| 문자열 테이블 | 대사를 JSON에 직접 적는다. 대화 시스템의 `strings_ko.json`·검사·패킹과 연결하지 않음 (다국어가 필요해지면 연결) |

| 입력 상태 관리만 있고 UI 스택이 없는 씬 | 확인 입력을 받지 못한다 (대화 상태로 바뀌지 않음). `LJS 시간` 항목을 함께 적용 |
