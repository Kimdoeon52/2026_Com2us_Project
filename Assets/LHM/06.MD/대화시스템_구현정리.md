### 대사 1개의 구성

| 칸 | 값 |
|---|---|
| `band` | Critical > Story > Reactive > Progress > Ambient > Fallback |
| `sub` | 같은 band 안 세부 순위 0~99 |
| `conditions` | `변수 연산자 값` 목록 (대사는 변수를 **읽기만**) |
| 소비 | `maxPlays`(1회 / N회) · `perEvent`(변수 값이 바뀌면 새 사건) · `group`(같은 묶음은 사건당 하나만) · `cooldown`(초) |
| `display` / `background` | bottom / fullscreen / intermission, 배경 ID |
| `formerIds` | 이전 ID (기록 이어받기) |
| 줄 | `speaker`(비우면 내레이션) · `expression` · `textKey` · `direction`(지문, 칭호 아래 하늘색) · `effects` |

- **선택 규칙:** 조건 통과 → band 높은 쪽 → sub 높은 쪽 → 조건이 많은(구체적인) 쪽
- **기본 대사 의무:** 말 걸기 풀은 조건 없는 대사가 하나 이상 필요. `"eventOnly": true` 풀(ID로만 재생)은 제외
- **연출 `effects`:** `zoom(1.2)` · `shake(0.3)` · `fadeOut(1, wait)` · `sound(id)` · `bgm(id)` · 표정. `wait`는 최대 3초에서 끊김

### 변수

| 묶음 | 변수 |
|---|---|
| `hunt.*` | `lastResult`(none/win/lose) · `lastBoss` · `lastDifficulty`(none/veryEasy/easy/normal/hard/hell) · `bossLoseCount` · `count`(사건 판정) · `winCount` · `loseCount` · `targetBoss` · `targetDifficulty` · `bossAttemptCount` |
| `rank.*` | `band`(1 / 2-10 / 11-30 / 31-100 / 101+) · `dailyChange` · `top10Reached`(no/yes, 한 번 yes면 유지) |
| `season.*` · `time.*` | `day` · `endingSoon`(D-7) · `weekday` · `month` |
| `race.*` | `id`(race1/race2/race3/final) · `stage` · `seasonFirst` |
| `player.*` · `story.*` | `usingBasicParts` · `coreLevel` · `chapter` |
| `auction.*` | `lastResult`(none/sold — 유찰 없음) · `settleCount` |
| `battle.*` (바크 순간에만 값이 있음) | `event`(none/playerPartBroken/bossPartBroken/bossGroggy) · `brokenPart`(NYH `BodyPart` 이름) · `bossPartId` · `playerBrokenCount` · `bossHpPercent` |

- bool 타입이 없어 예/아니오는 `no` / `yes` enum

## 4. 런타임 구조

| 구성 | 핵심 |
|---|---|
| `DialogueManager` | 로드 순서 **패킹 → 원본 JSON → 기본 대사 폴백**. `Talk(poolId)`, `PlayDialogue(id)`(기록), `CanPlay(id)`(기록 안 함), `PlayDialogueIfAvailable(id)`(튜토리얼용, 봤으면 false), `TryPickLine`(바크 · 관중 · 혼잣말: 기록만), `TryPlayBest`(반응 말풍선: 기록 + 저장) |
| 폴백 모드 | 말 걸기 = `...` 한 줄, 선택지 이름은 내장 문구, 이벤트 · 바크 · 말풍선 없음, **세이브 읽기 · 쓰기 안 함**. `Debug Force Fallback`으로 시험 |
| `DialogueBox` | 타자기, 스킵(안 읽은 줄이 있으면 확인 창) · 오토(`1초 + 글자 수 × 0.05초`) · 빨리감기(읽은 줄만, 0.06초 간격), 백로그, 입력 무시(시작 0.25초 · 줄마다 0.12초), `{키}` 치환 `SetTextArgument`, `HoldOnLastLine`, LOG · AUTO · SKIP 버튼(`DialogueBoxControls`) |
| 세이브 `DialogueSaveSystem` | `dialogue_save.json` = `{checksum, data}`. SHA-256 + 고정 salt. 임시 파일 → 교체 + `.bak`. 본 파일 실패 → 백업, 둘 다 실패 → **저장 금지**(Shift+F12로 초기화). `data`: 대사 기록 · 사건 표시 · 읽은 줄(`readLines`, 문자열 키 기준) · 변수. **형식이 바뀌면 Shift+F12 필요** |
| UI 스택 | `IUiStack` / `UiStack.Current` (`Push` · `Remove`, Pop 아님). `TimeSystemUiStack`이 LJS 시간과 연결: 첫 UI → `UIOpen`, 마지막 해제 → `Running`, 전투 → `Combat`, LJS UI(달력 · 지도 · 랭킹)도 1개로 셈. 바크 · 말풍선은 등록 안 함 |
| 00시 | LJS `OnDayRankingRestore` → 프레임 끝에 `DaysPassed(일수)` → `DialogueDayProcessor`(배포 빌드에서도 동작) → 트리거 평가. LJS 한 달 28일, **1일 = 일요일** 가정. `season.day` · `endingSoon`은 아직 더미 계산 |
| `InputModeController` (-100) | LHM 전용 `03.Data/Input/RealSteelInput.inputactions`의 Field / Battle / Dialogue 중 하나만 켬. UI 스택 > 0이면 Dialogue. 대화가 끝나면 **키를 모두 뗄 때까지** 대기. `SetBaseMode(Field/Battle)` |
| NPC | `NpcInteractable`(역할 · poolId · speakerId · 반경 · `greetingPoolId` · 클로즈업 점, 켜진 NPC를 `Active` 목록에) · `PlayerInteractor`(실행 순서 -95 = 브리지보다 먼저, 반경 안 최근접 NPC를 수평 거리로 · 잡은 대상은 +0.3m 유지, `[E] 이름`은 `Canvas.willRenderCanvases`에서 카메라 이동 뒤 위치 맞춤) · `NpcChoiceMenu`(숫자키 1~9, 작업대 제작 · 수리, 경매 메뉴) · `CameraStepBlock`(NPC · 문 앞 Q/E 카메라 회전 막기, 막는 쪽 개수로 관리) |
| `DialogueEventQueue` | 트리거는 **대사 ID만** 가리키고 판정은 대사 자신의 조건. 출력 순서 story → system → bubble. 필드 대기(대화 · UI 없음, Field, 키 뗌) + 0.5초 후 출력. `EvaluateMidnight()` · `Evaluate(label)` · `Enqueue(id, kind)`. **대기열은 저장 안 함** (다음 00시에 다시 쌓임) |
| 보스 기록 `BossProgressStore` | 보스별 도전 · 패배 · 최고 난이도 · 지역 클리어. `IBossRaceProgress` · `IRobotPartStatus`(내구도 = KDU 장착 파츠) 구현. `boss_progress.json` 저장 · 전투 씬 자동 생성 · KKH `RecordHunt` 수신 (11-19) |
| `BossEntryDialogue` | `Play(보스, 난이도, 도전 수, 패배 수, 끝나면)` → 대상 보스 값을 변수에 채우고 `boss_entry` 선택. 재생 실패해도 바로 `끝나면` 호출 |
| `HuntDeparture` | 토벌 신청 → 난이도 UI → 진입 대사 → `BattleManager.SetPreBattleDifficulty` → `SceneLoader`(LJS 로딩 화면 → 프리팹 → 비동기)로 전투 씬. 도전 +1. 정비하기 → YJW 수리창(`CraftingWindowBridge`) |
| `BattleBarkPlayer` | KKH `CombatDataHub.OnPlayerPartBroken` · `BossControllerBase.OnGroggyChanged` 구독, 보스 부위 파괴는 `gimmickStates`를 매 프레임 비교. 첫 줄만, 0.8초 이내 연속 무시, 대화창이 열려 있으면 무시, 세이브 안 씀. `PlaySubtitleDialogue(id)`(여러 줄 자막) |
| 말풍선 | `BubbleManager`(8개 재사용, 2.5초 + 페이드) · `CrowdBubbles`(2.5~5초마다, 동시 3개) · `NpcBubbles`(반응 = 첫 줄 화자의 NPC 4m 안에서 1회 · 저장, 혼잣말 = `mono_` + speakerId, 3m 진입 순간 · 10초 간격). 대화 중 숨김 |
| `FieldInputBridge` (-90) | UI가 열린 동안 SYS `RSSimpleCharacter` 끄기(애니메이터 `Speed` = 0) + KDU `ScrapInputGate.Push`, 키를 뗀 뒤 해제. Tab · C · K 잠금(상점 창 열린 동안 제외), NPC 범위 안에서 고철 안내 숨김, 미니게임 중 NPC 상호작용 끄기 |
| 보스 선택 화면 입력 | `BossUiInputGate`: 튜토리얼 진행 중 · 대화창 열림이면 지역 · 난이도 선택 화면 입력 무시, 풀린 뒤 입력 무시 0.2초 다시 적용 |
| 메인 메뉴 해상도 | `ResolutionLimit`: Heat 해상도 목록에서 1600×900 미만 숨김 (모니터가 더 작으면 그대로) |
| 기타 | `ShortcutHelpOverlay`(Home 단축키 안내) · `SoundManager` · `TutorialPanel` · `DoorInteractable`(문 → 씬 이동, `doorId` 짝 도착 시 캡슐 겹침 검사로 빈자리 선택) · `AuctionBridge`(LSH 경매) · `CraftingWindowBridge` · `SceneLoader` · `BattleDifficultyLabel`(전투 화면 난이도 글자) |

## 6. 대사 작성 — CSV

```
(처음 1번) 대화 툴 → CSV 내보내기 → Sheets/풀이름.csv
엑셀 · 구글 시트 편집 → CSV UTF-8로 Sheets에 덮어쓰기
→ Unity가 자동 변환: CSV 읽기 → 키 생성 → 검사 → 통과 시 풀 JSON + strings_ko.json 저장 (실패하면 아무것도 안 씀)
```

| 칸 | 적는 법 |
|---|---|
| 1행 (선택) | `#eventOnly, true` |
| 머리글 | `id, band, sub, conditions, consume, display, background, formerIds, speaker, expression, direction, text, effects, key` (순서 자유) |
| 행 | **한 행 = 대사 한 줄.** 대화 첫 줄에만 `id` ~ `formerIds`. 빈 행 · `#` 행은 무시 |
| `conditions` | `hunt.lastResult == lose; hunt.lastBoss == boss.wheel` (`;` 구분, 값에 `;` 금지) |
| `consume` | `maxPlays=1; perEvent=hunt.count; group=guild_hunt_reaction; cooldown=3` |
| `effects` | `zoom(1.2); shake(0.3); sound(sfx.stamp); fadeOut(1, wait)` |
| `text` / `key` | 실제 문장 / 비우면 `대화ID.줄번호` 자동 생성. key만 있고 text가 비면 기존 문장 사용 |

- **CSV가 있는 풀은 CSV가 원본** — JSON을 직접 고치면 다음 변환 때 덮어써짐. 변수 · 트리거는 CSV 대상 아님
- 사라진 키는 다른 풀도 안 쓰면 `strings_ko.json`에서 삭제. 읽은 줄 기록은 키 기준 → 문장만 고치면 "읽음" 유지
- 엑셀: **"CSV UTF-8(쉼표로 분리)"** 로 저장 (그냥 "CSV"는 거부). `key` 칸은 텍스트 서식 권장
- 대화 툴 → 데이터 도구 → **대사 미리보기**: Play 없이 변수를 바꿔 나올 대사 · 후보 순위 · 00시 대기열 확인 (게임과 같은 `DialogueSelector` 사용)
