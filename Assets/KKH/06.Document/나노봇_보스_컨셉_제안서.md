> **전제**: `RSNanoBoss` 엔진(가이드/리그, `bind` 유체↔기계, `Bound/Free/Debris`, 모래 물리, 스프라이트 모핑, 앞판/뒷판)을 재사용한다.

## 1. 스크랩 레기온 (Scrap Legion) — 고철 흡수형 거인

> "고물상의 폐기물이 하나의 의지로 뭉쳤다." — 우리 게임 정체성(고철)과 가장 잘 맞는 보스

### 컨셉
경기장 곳곳의 **고철 더미(기물)** 를 빨아들여 몸집·질량을 키우는 나노봇 거인. 체력 = 봇 수(질량). 먹을수록 강해지지만 느려진다.

### 핵심 기믹
| 기믹 | 내용 | 엔진 활용 |
|---|---|---|
| **고철 흡수** | 맵 양끝 고철 더미 3~5개. 보스가 다가가 흡수하면 질량 +15%, 공격력 상승 | `Debris` → `Bind(G_Blob)` 재흡수 (`Absorb`) |
| **고철 더미 파괴** | 플레이어가 **[기물 파괴]** 태그 스킬로 더미를 먼저 부수면 흡수 불가 | 기믹 태그 `ObjectBreak` |
| **과부하** | 질량 150% 초과 시 몸이 무너져 4초 그로기(받는 피해 1.5배) | `bind` 0 → 몸 붕괴 |
| **질량 = 크기** | 맞을수록 실제로 작아지고 빨라진다 → 후반 난이도 반전 | `BlobSize(guideCount)` |

### 공격 패턴
1. **고철 해머** — 팔을 거대 망치로 응축(`bind` 0→1, 착 잠김) → 내려찍기. 착지 시 고철이 사방으로 튐 (`Fire` 링). 타격: **팔**
2. **스크랩 폭우** — 몸에서 고철 덩어리를 위로 쏘아 올려 낙하 (`Rain` 에미터). 그림자 예고. 타격: **머리**
3. **집어삼키기** — 바닥을 파도처럼 쓸며(`fillToFloor` 체인) 플레이어를 몸 안에 가둠 → 연타로 탈출, 실패 시 지속 피해 + **다리** 내구도
4. **분열** — 2페: 체력 50%에서 작은 덩어리 3개로 갈라짐. 각자 다른 패턴. 하나씩 잡으면 남은 쪽에 흡수됨

### 매력 포인트
- "먹이를 끊을지 / 본체를 칠지" 매 순간 선택
- 시각적으로 몸이 실제로 커지고 줄어듦 → 체력바 없이도 상황이 읽힘

## 2. 미믹 (Mimic / 카피캣) — 플레이어 복제형

> "네 기체를 해석했다. 이제 그건 내 것이다."

### 컨셉
전투 시작 시 **플레이어가 장착한 5파츠와 QWER 스킬을 스캔**해 같은 형태의 나노봇 기체로 변신. 플레이어 빌드마다 보스가 달라진다 → 반복 플레이 가치 최상.

### 핵심 기믹
| 기믹 | 내용 | 엔진 활용 |
|---|---|---|
| **스캔** | 시작 3초간 빛이 훑음 → 플레이어 실루엣을 스프라이트 시트로 베낌 | `RSNanoSpriteShape` / 스프라이트 모핑 |
| **스킬 복제** | 플레이어가 쓴 스킬을 2초 뒤 그대로 따라 씀 (지연 거울) | 입력 기록 큐 |
| **약점 = 내 약점** | 플레이어가 파괴된 파츠가 있으면 미믹도 그 파츠가 깨져 있음 | `partStates` 참조 |
| **복제 오류** | 스킬을 너무 많이 베끼면 과열 → 형태 붕괴 그로기 | `bind` 저하 |

### 공격 패턴
1. **미러 스킬** — 내가 Q를 쓰면 2초 후 미믹도 Q. 내 스킬을 알면 피할 수 있음
2. **과장 복제** — 내 스킬을 2배 크기로 베낌 (몸 스케일 ↑)
3. **역스캔** — 내 HUD 파츠 아이콘 중 하나를 붉게 표시 → 그 부위로 집중 공격 (해당 파츠 내구도 타격)
4. **모습 붕괴** — 2페: 형태를 유지 못 하고 플레이어 + 이전 보스들 모습을 섞어 랜덤 변신

### 매력 포인트
- 빌드 다양성(파츠 조합)이 곧 보스 다양성
- "나와 싸운다"는 서사적 쾌감 + 공략법 = 자기 빌드 이해

## 3. 코어 하이브 (Core Hive) — 여왕 + 군체

### 컨셉
보스 본체는 공중에 떠 있는 거대한 나노 구름. 그 안에 **진짜 코어 1개 + 가짜 코어 4개**가 돌아다닌다. 진짜를 맞혀야만 데미지.

### 핵심 기믹
| 기믹 | 내용 |
|---|---|
| **코어 셔플** | 코어 5개가 구름 안을 돌다 섞임. 진짜는 공격 직전 0.3초 빛남 |
| **가짜 코어 타격** | 가짜를 치면 터지며 반격 탄막 |
| **일꾼 봇** | 구름에서 작은 봇 무리(`Swarm` 리그)가 떨어져 나와 플레이어를 추적. 처치 시 실린더 탄 +1 |
| **보호막 재생** | 일꾼이 코어로 돌아가면 보호막 회복 → 일꾼 정리 우선 |

### 공격 패턴
1. **벌떼 돌격** — 무리가 S자로 플레이어를 휘감음 (`RoamTarget`)
2. **코어 레이저** — 진짜 코어가 노출되며 빔. 노출 시간이 딜 타임
3. **구름 덮기** — 화면 상단을 구름이 덮고 랜덤 지점에 봇 비 (`Rain`)
4. **여왕 강림** — 2페: 코어들이 합쳐져 인간형 여왕으로 → 근접전

## 4. 샌드 타이드 (Sand Tide) — 모래/지형 변형형

> 엔진의 `NanoSandJob` 모래 물리를 가장 극적으로 쓰는 보스

### 컨셉
몸이 없다. **경기장 바닥 전체가 보스**. 모래 언덕이 솟고 꺼지며, 바닥에서 손·가시·파도가 솟는다.

### 핵심 기믹
| 기믹 | 내용 |
|---|---|
| **지형 변형** | 매 20초 바닥이 언덕/구덩이로 재배치 → 점프 동선 바뀜 |
| **모래 늪** | 일부 바닥이 유체(`bind` 0)가 되어 다리 이동속도 -50% |
| **결정화 기둥** | 3개의 기둥(약점)이 랜덤 위치에서 솟음. **[하단 부위]** 태그로 파괴 |
| **모래 쌓임** | 맞은 봇이 실제로 쌓여 발판이 됨 → 높은 곳 약점 공략 경로 |

### 공격 패턴
1. **사구 파도** — 바닥이 파도처럼 솟아 덮침 (예제 `파도 → 가시` 리그 그대로 활용). 타격: **다리**
2. **가시 밭** — 발밑 웅덩이가 요동치다 가시로 굳음 (`bumpAt` + `feedFrom`)
3. **모래 손** — 바닥에서 거대 손이 솟아 잡기
4. **흡입 소용돌이** — 중앙으로 모래가 빨려들며 플레이어도 끌려감

### 매력 포인트
- 구현 비용 대비 효과 최고 (엔진 기능 대부분 이미 존재)
- 1지역 보스의 "못판" 기믹 감각을 확장

## 5. 아이언 오케스트라 (Iron Orchestra) — 리듬 탄막형

### 컨셉
A사가 만든 공연용 나노봇 지휘자. BGM 박자에 맞춰 공격한다. 지휘봉을 휘두를 때마다 봇 악단이 탄막을 연주.

### 핵심 기믹
| 기믹 | 내용 |
|---|---|
| **박자 판정** | 박자에 맞춰 D 공격 시 데미지 2배 + 실린더 2발 |
| **악기 파트 4개** | 타악(충격파)·현악(레이저)·관악(탄막)·지휘자(본체). 악기를 부수면 해당 패턴 소멸 |
| **템포 업** | 페이즈마다 BPM 상승 (난이도 레이어 = BPM) |
| **불협화음** | 박자를 3번 연속 놓치면 보스 회복 |

### 공격 패턴
1. **드럼롤** — 4박마다 바닥 충격파 (점프 회피)
2. **현의 선율** — 화면을 가로지르는 레이저 줄 5개가 악보처럼 위아래 이동
3. **팡파르** — 부채꼴 탄막 + 나선(`Spiral` 에미터)
4. **피날레** — 모든 악기 동시 연주. 정확한 박자로만 틈이 생김

## 6. 패러사이트 (Parasite) — 파츠 감염형

> 우리 게임의 "파츠 내구도 / 스킬 봉인" 시스템을 정면으로 비튼 보스

### 컨셉
나노봇이 플레이어 기체에 **달라붙어 파츠를 감염**시킨다. 감염된 파츠는 스킬이 보스 편으로 넘어간다.

### 핵심 기믹
| 기믹 | 내용 |
|---|---|
| **감염 게이지** | 보스 봇에 닿을수록 해당 부위 감염 게이지 상승 → 100% 시 그 파츠 스킬 봉인 |
| **스킬 강탈** | 감염된 파츠의 스킬을 보스가 사용 |
| **정화** | 회피(Space) 무적 중 감염 봇이 털려나감. 또는 감염 부위로 D 3회 |
| **숙주 공략** | 보스 본체는 작고 빠름. 감염시킨 봇을 회수하러 올 때가 딜 타임 |

### 공격 패턴
1. **포자 살포** — 느리게 떠다니는 봇 구름. 닿으면 감염
2. **촉수 그랩** — `Whip` 사슬로 붙잡아 감염 가속
3. **강탈 스킬** — 내 Q/W/E/R을 보스가 쓴다
4. **변이** — 2페: 감염 파츠 수만큼 보스가 팔/다리를 자라게 함

### 매력 포인트
- 체력보다 "파츠를 지키는" 긴장감 → 하드코어 파괴 시스템과 시너지

## 7. 프로토콜 A-0 (A사 경비 메카) — 형태 변신형

### 컨셉
A사가 레이스 감시를 위해 배치한 나노봇 경비병. 상황에 맞춰 **5가지 무기 형태**로 즉시 재구성한다. A사 총수의 의심도가 높을수록 등장.

### 형태 순환
| 형태 | 공격 | 파괴 조건 (부위 파괴) |
|---|---|---|
| **블레이드** | 근접 3연베기, 대검 잔상 | **[상단 부위]** 로 칼날 파괴 → 블레이드 형태 봉인 |
| **캐논** | 차지 빔 (`Ring` 포신) | 포신 차지 중 **[원거리 기물]** 타격 |
| **실드** | 전방 무적 + 돌진 | 뒤로 돌아가 **[중단 부위]** |
| **드릴** | 바닥을 파고 들어가 발밑 기습 | 튀어나온 직후 **[하단 부위]** |
| **스웜** | 몸을 해체해 사방 탄막 | 재조립 순간 중앙 코어 노출 |

### 핵심 기믹
- 파괴한 형태는 다시 못 씀 → 형태를 다 부술수록 패턴이 단순해짐 (부위 파괴 보상)
- 헬: 형태 2개 동시 합체 (블레이드 + 캐논 = 레이저 블레이드)

## 8. 미러 레이어 (Mirror Layer) — 앞판/뒷판 2차원 전투

> 엔진의 `back` (앞판 ↔ 뒷판, 화면 안쪽 9m) 기능을 핵심 기믹으로

### 컨셉
보스가 **화면 안쪽(배경)과 바깥(전투면)을 오간다**. 배경에 있을 땐 맞힐 수 없고, 거대하게 보이며 공격을 준비한다. 지역 2 보스 "쿄다이"의 레이어 판정 규칙을 나노봇으로 확장.

### 핵심 기믹
| 기믹 | 내용 |
|---|---|
| **레이어 이동** | 뒷판(어둡게, 무적) ↔ 앞판(밝게, 피격 가능) |
| **그림자 예고** | 뒷판에서 공격하면 앞판에 그림자가 먼저 드리움 |
| **반사 거울** | 경기장 양쪽 거울 기물. 플레이어 탄을 반사해 뒷판 보스 타격 가능 |
| **끌어내기** | 뒷판에서 손을 뻗을 때 그 손을 때리면 앞판으로 끌려나옴 |

### 공격 패턴
1. **배경 투척** — 뒷판에서 거대 덩어리를 던져 앞판에 착탄 (`Rain` z → 0)
2. **화면 뒤 가시** — 기존 `BackSpike` 그대로
3. **차원 압착** — 앞판·뒷판 양쪽에서 동시에 손바닥이 덮침
4. **반전** — 2페: 플레이어가 강제로 뒷판으로 끌려감 (조작 반전)

## 9. 그레이브 로봇 (Grave Robot) — 패배 기록 소환형 (히든)

### 컨셉
지금까지 **플레이어가 패배로 잃은 파츠(잔해, Wreck)** 를 나노봇이 주워 모아 만든 망령. 세이브 데이터의 `Wrecks` 목록을 그대로 읽는다.

### 핵심 기믹
| 기믹 | 내용 |
|---|---|
| **잃어버린 파츠** | 보스의 머리/팔/다리 = 내가 잃었던 실제 파츠 (스프라이트 + 스킬) |
| **회수** | 보스 부위를 파괴하면 그 파츠를 잔해 상태로 되찾음 (복구 가능) |
| **트라우마** | 내가 가장 많이 진 보스의 패턴을 섞어 씀 (`BossProgressStore.LosesOf`) |

### 매력 포인트
- 하드코어 파괴 시스템의 상처를 보상 기회로 바꿈 → 감정적 몰입
- 데이터 기반이라 플레이어마다 완전히 다른 보스

## 10. 아버지의 장치 (최종 보스) — 다중 페이즈 집대성

> 기획서: "코어의 결함을 메울 장치는 길드 레이스 최종 보스 안에 있다."

### 컨셉
아버지가 설계도를 숨긴 보안 장치. 나노봇으로 이루어진 거대 금고 겸 수호자. 앞의 보스들 기믹을 모두 학습해 순차 재현하며, 마지막엔 **코어 v.2의 짝**이 되는 모습으로 수렴한다.

### 페이즈 구성
| 페이즈 | 형태 | 기믹 |
|---|---|---|
| **1. 금고** | 기하학 정육면체 (`bind` 1, 완전 기계) | 회전하는 면마다 다른 공격. 잠금 장치 4개 파괴 |
| **2. 기억** | 이전 지역 보스들(호이루·쿄다이 등)을 나노봇 실루엣으로 재현 | 각 보스 대표 패턴 1개씩 메들리 |
| **3. 시련** | 플레이어 미믹 (#2 기믹) | 내 빌드 vs 내 빌드 |
| **4. 아버지** | 인간 실루엣, 공격하지 않음 | 대사 연출 + 마지막 선택 (A사 총수 코어 v.1 대결로 연결) |

### 매력 포인트
- 서사 클라이맥스 + 지금까지 배운 모든 파훼법의 졸업시험
- 4페이즈 "공격하지 않는 보스"로 감정 반전

## 11. 크로노 스웜 (Chrono Swarm) — 시간 되감기형

> 엔진의 "같은 입력이면 같은 결과" (해석적 스프링, 결정론적 재시뮬) 특성을 기믹으로

### 컨셉
자신의 움직임을 **녹화하고 되감는** 나노봇. 피한 공격이 되감겨 반대 방향으로 다시 날아온다.

### 핵심 기믹
| 기믹 | 내용 |
|---|---|
| **되감기** | 3초 전 공격을 역재생 (탄막이 원점으로 돌아가며 다시 판정) |
| **잔상 분신** | 3초 전 자기 위치에 반투명 분신. 분신도 공격함 |
| **시간 정지 코어** | 보스가 되감는 동안 코어가 노출 → 딜 타임 |
| **역설** | 되감는 중 분신과 본체가 겹치면 자멸 데미지 (플레이어가 유도) |

### 공격 패턴
1. **부메랑 탄막** — 나갔다가 되감겨 돌아옴
2. **잔상 베기** — 본체 + 분신 2개가 시간차 베기
3. **시간 고정** — 화면 일부 영역의 탄을 정지 → 해제 시 일제 발사

## 12. 마그넷 콜로서스 (Magnet Colossus) — 자력 극성형

### 컨셉
금속 나노봇을 자력으로 묶은 거인. 플레이어 로봇도 금속이라 끌리고 밀린다.

### 핵심 기믹
| 기믹 | 내용 |
|---|---|
| **극성 전환** | 보스 몸 색이 빨강(N)/파랑(S)로 바뀜. N일 때 플레이어가 끌려가고 S일 때 밀려남 |
| **자력 파츠** | 플레이어 팔 파츠 무게가 무거울수록 끌림 강함 (빌드 영향) |
| **자석 기둥** | 경기장 기물. 극성을 맞추면 보스 탄막을 흡수 |
| **분해** | 극성 반전 순간 봇이 흩어졌다 재결합 → 재결합 중 코어 노출 |

### 공격 패턴
1. **흡인 + 펀치** — 끌어당겨서 주먹
2. **철편 폭풍** — 모든 탄이 플레이어를 향해 휘어짐 (`accel` 유도)
3. **반발 충격파** — 밀어내며 벽에 충돌 시 추가 피해

## 13. 공통 설계 가이드라인

### 13-1. 게임 시스템 연동 체크리스트
- [ ] 패턴마다 **타격 부위(머리/팔/다리)** 지정 → 파츠 내구도 감소 (기획서 규칙)
- [ ] 패턴 종료 후 **1초 딜 타임** (보스 공통 규칙)
- [ ] 파훼 수단은 **기믹 태그**(기물 파괴/상단/중단/하단/원거리)와 연결 → 파츠 빌드에 의미 부여
- [ ] 난이도 5단계: `telegraph`, `recover`, `speed`, `chain` 배율 + 패턴 풀 확장 (`RSNanoBossBrain.Difficulties` 그대로)
- [ ] 체력 = 질량(봇 수) → 체력바 대신 몸 크기로 상태 전달

### 13-2. 나노봇 연출 공식
1. **예고 = 봇이 흘러가는 모습** (덩어리 → 무기 형태로 모이는 시간이 곧 텔레그래프)
2. **타격 순간 = `bind` 0 → 1** (유체가 순간 결정화, 빛 물결)
3. **딜 타임 = 형태 유지 + 코어 노출**
4. **피격 = 봇이 떨어져 모래로 쌓임** (손맛 + 맵에 흔적)

### 13-3. 엔진 기능 ↔ 보스 매핑
| 엔진 기능 | 가장 잘 쓰는 보스 |
|---|---|
| `Absorb` / `Debris` 재흡수 | 스크랩 레기온, 코어 하이브 |
| 스프라이트 모핑 (`RSNanoSpriteShape`) | 미믹, 그레이브 로봇, 아버지의 장치 |
| 모래 물리 (`NanoSandJob`) | 샌드 타이드 |
| 앞판/뒷판 (`back`) | 미러 레이어 |
| 사슬 물리 (`ChainStep`) | 패러사이트, 프로토콜 A-0 |
| 결정론적 재시뮬 | 크로노 스웜 |
| `Free` 탄 + `accel` | 마그넷 콜로서스, 아이언 오케스트라 |
