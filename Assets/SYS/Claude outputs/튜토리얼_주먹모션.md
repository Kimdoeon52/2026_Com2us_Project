# 튜토리얼 — 주먹 돌진 모션 처음부터 만들기

목표: 보스가 주먹을 만들고, 뒤로 당겼다가, 앞으로 돌진해 때리고, 흩어지는 2초짜리 공격.
걸리는 시간: 약 15분. 프레임은 전부 1/60초 기준.

---

## 1단계. 리그 만들기

1. `SYS/Scenes/NanoBoss_Test` 를 연다
2. 하이어라키에서 **보스**(나노봇 군집이 붙은 오브젝트)를 클릭한다
3. 메뉴 `GameObject → RE_AL STEEL → 나노봇 리그 → 빈 리그`
   - 보스 아래에 `나노봇 리그` 가 생기고, **나노봇 동작 창**이 열린다
   - 리그 안에 `플레이어` 오브젝트도 생긴다 (건드리지 않는다)
4. 하이어라키에서 리그 이름을 `리그_내주먹` 처럼 바꾼다

## 2단계. 주먹 부위 넣기

1. 하이어라키에서 `리그_내주먹` 을 클릭한다
2. 인스펙터 **`+ 부위 프리셋 ▾` → `주먹`**
   - `팔`(줄기) → 그 끝에 `주먹`(덩어리) → `마디1~4` 가 생긴다
3. 씬 뷰에 반투명 모양이 보인다. 봇은 리그를 선택하고 있는 동안 저절로 모여든다
4. (선택) 모양 다듬기 — `팔` 을 고르면 씬 뷰에
   - **흰 점** (관절): 끌어서 팔 방향 · 길이
   - **노란 네모** (두께): 끌어서 굵기
   - `주먹` 을 고르면 **노란 네모 2개**로 가로 · 세로 크기

> 주먹이 향하는 쪽 = 오른쪽(+x) = 플레이어 쪽. 오른쪽을 보는 것으로만 만들면 플레이 중 플레이어가 왼쪽일 때 자동으로 뒤집힌다.

## 3단계. 클립 만들고 미리보기 켜기

1. 나노봇 동작 창 맨 위 **`새 클립`** → 애니메이션 창이 열린다
2. 나노봇 동작 창 **`애니메이션 창 열고 미리보기 켜기`**
   - 위에 `프레임 0 / 180` 이 보이면 준비 끝
3. 애니메이션 창과 나노봇 동작 창을 나란히 둔다

> 이제부터 어느 프레임으로 가든 봇이 그 프레임 모습으로 고정된다.

## 4단계. 주먹이 모이게 하기 (프레임 0 → 30)

1. 나노봇 동작 창 **`동작`** 탭
2. 위의 `⏮` 로 **프레임 0** 에 둔다
3. **길이** 슬라이더를 **30** 으로
4. 부위마다 **`나타나기`** 를 누른다 — `팔` · `주먹` · `마디1` · `마디2` · `마디3` · `마디4` (6번)
5. 띠를 보면 부위마다 회색 줄(보임)이 프레임 0~30 에 차오른다
6. `▶ ½` 로 재생해 본다 → 덩어리에서 봇이 흘러나와 팔 뿌리부터 주먹까지 차오른다. `■` 로 멈춘다

## 5단계. 돌진 (프레임 30 → 88)

1. 나노봇 동작 창 띠에서 **프레임 30** 을 클릭한다 (위 표시가 `프레임 30`)
2. **`행동 블록`** 탭 → **`돌진`**
3. **움직일 것** 칸에 하이어라키의 **`팔`** 을 끌어다 놓는다
4. 값은 그대로 둔다 — 거리 6 · 준비 18 · 돌진 8 · 뻗은 채 12 · 복귀 20
5. **`지금 프레임부터 만들기`**
   - 이렇게 들어간다:
     - 프레임 30 ~ 48: 뒤로 살짝 당기며 노랗게 빛남 (예고)
     - 프레임 48 ~ 56: 6m 돌진, 빨간 판정 + 화면 흔들림
     - 프레임 56 ~ 68: 뻗은 채 버팀
     - 프레임 68 ~ 88: 제자리로 돌아옴
6. `⏮` → `▶ ½` 로 처음부터 본다

## 6단계. 흩어지기 (프레임 95 → 115)

1. 띠에서 **프레임 95** 를 클릭
2. **`동작`** 탭, **길이 20**
3. 부위마다 **`사라지기`** — `팔` · `주먹` · `마디1~4` (6번)
4. 끝 자리(주먹 쪽)부터 봇이 풀려 덩어리로 돌아간다

## 7단계. 점검하고 저장

1. **`점검`** 탭을 연다
   - 노란 경고가 있으면 문장대로 고치거나 **고치기** 버튼을 누른다
   - 경고가 없으면 OK
2. (선택) 클립 끝 정리 — 새 클립은 3초(프레임 180)로 시작한다. 애니메이션 창에서 `리그_내주먹 : Shake` 줄의 **맨 끝 키(3:00)** 를 지우면 공격이 2초 안쪽으로 끝난다
3. **Ctrl + S** 로 씬 저장 (리그는 씬 안의 오브젝트라 씬을 저장해야 남는다)

## 8단계. 보스가 쓰게 하기

1. 하이어라키에서 **보스** 클릭 → 인스펙터 **나노봇 보스 두뇌**
2. **리그 패턴** 목록에서 `+`
   - Rig = `리그_내주먹`, Clip = 방금 만든 클립 (`새 공격`)
   - Phase1 · Phase2 체크, From Difficulty 1, Weight 1
3. 씬 저장 → **플레이**
4. 왼쪽 위 HUD → **`패턴 직접 실행`** 체크 → `리그 패턴 (애니메이션)` 아래 **클립 이름 버튼**을 누른다

끝. 보스가 주먹을 만들어 돌진한다.

---

## 느낌 다듬기 (선택)

부위를 고르고 인스펙터 **느낌** 의 프리셋 버튼을 눌러 같은 클립을 다시 본다.

| 이렇게 하고 싶다 | 고를 부위 | 바꿀 것 |
|---|---|---|
| 주먹이 더 묵직하게 | `주먹` | 프리셋 **단단** → **반응** 을 8~10 으로 |
| 팔이 채찍처럼 늦게 따라오게 | `팔` | **끝 늦음** 6~10 |
| 돌진 뒤 주먹이 출렁이게 | `주먹` | **출렁임** 0.4 |
| 더 빨리 모이게 | 전부 | 4단계 **길이** 를 20 으로 줄여 다시 `나타나기` |
| 예고를 더 길게 | — | 5단계 **준비** 를 24~30 으로 (점검 탭이 짧다고 하면) |

## 막혔을 때

| 증상 | 해결 |
|---|---|
| 봇이 안 보인다 | 하이어라키에서 리그(또는 그 부위)를 선택하고 있어야 미리보기가 돈다 |
| 프레임을 옮겨도 봇이 안 바뀐다 | 애니메이션 창 왼쪽 위 **미리보기(Preview)** 버튼이 켜져 있는지 확인 |
| 버튼을 눌러도 키가 안 들어간다 | 동작 창 위에서 클립 이름이 방금 만든 클립인지 확인 |
| "리그 원점에 잡힌 키를 지웠습니다" | 리그 자체가 아니라 `팔` 같은 **부위**를 움직여야 한다 (정상 동작) |
| 판 사이가 벌어져 성글다 | 부위 인스펙터 **봇** → `크기에 맞게` |

> 이 도구는 아직 유니티에서 충분히 검증되지 않았다. 위 설명과 다르게 동작하는 버튼이 있으면 그 단계 번호와 함께 알려 주면 고친다.
