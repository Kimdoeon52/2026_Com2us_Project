# RS Terrain — 범용 옥토패스풍 지형 도구

요소를 씬에 배치하면 지형이 만들어지고, 그 위를 브러시로 다듬는다.
코드를 고치지 않고 어떤 맵이든 만들 수 있다.

## 시작

1. `GameObject > RE_AL STEEL > RS 지형` (또는 `Tools > RE_AL STEEL > Stage > RS 지형 만들기`)
2. 인스펙터에서 크기·격자·노이즈 설정
3. **요소 추가** 버튼으로 둔덕 · 더미 · 웅덩이 · 작업장 · 길 · 경사로 · 배수로를 놓는다
4. 요소를 옮기거나 핸들로 크기를 바꾸면 지형이 자동으로 다시 만들어진다 (마우스를 놓을 때)
5. 손질은 **브러시**로 (올리기 · 내리기 · 평탄화 · 부드럽게 · 칠하기)

바로 보고 싶으면 인스펙터 맨 아래 **예제: 폐철장 40x40**.

## 요소

| 요소 | 하는 일 | 씬 핸들 |
|---|---|---|
| 둔덕 · 절벽 (RSPlateau) | 층진 절벽 + 부푼 테두리. 올리기 / 깎아 내리기 | 사각 크기 |
| 더미 (RSHeap) | 봉우리 여러 개 + 층진 고철 표면, 둘레 조각 흩뿌림 | 반경 |
| 웅덩이 (RSPit) | 파인 자리 + 턱, 물 고임 | 반경 |
| 작업장 · 평탄 (RSPad) | 오브젝트 Y 높이로 평탄화. 깨진 슬래브 옵션 | 사각 크기 |
| 길 · 배수로 (RSSpline) | 점을 이은 선. 길 = 바퀴 자국 / 경사로 = 점 높이로 평탄화 / 배수로 = 파고 물 채움 | 점 이동 · Shift+클릭 추가 · Ctrl+클릭 삭제 |
| 폐자재 (RSScatter) | 반쯤 묻힌 콘크리트 파편 · 철판 · 파이프 · 타이어 · 드럼통. 원 안 또는 지형 전체. 길·콘크리트·진흙·급경사는 피함. 지형 모양은 안 바꿈 | 반경 |

- **order** 가 낮은 요소부터 적용되고, 나중 요소가 앞의 결과를 덮는다 (기본: 둔덕 0 → 더미 10 → 웅덩이 20 → 작업장 30 → 길 40 → 배수로 50)
- **strength** 로 요소 세기를 0~1 로 조절
- 오브젝트를 Y 축으로 돌리면 요소도 돈다
- **정점 고정** (작업장 · 배수로) 을 켜면 그 자리는 정점 흔들기를 안 해서 반듯하다 — 다리 받침용

## 지면에 붙이기

`Tools > RE_AL STEEL > Stage > 선택한 오브젝트를 지면에 붙이기` — 다리 · 펜스 · 소품을 RS 지형 높이에 맞춰 내려 앉힌다.
`(기울기 맞춤)` 은 지면 경사에 맞춰 눕힌다. 콜라이더가 없어도 된다.

## 브러시

인스펙터 브러시 섹션에서 도구를 고르고 씬 뷰에서 드래그.

- Shift = 반대 (올리기 ↔ 내리기, 칠하기 → 칠 지우기)
- `[` `]` = 반경
- 평탄화: Ctrl+클릭으로 높이 찍기
- 칠하기 레이어 '바탕' = 요소가 칠한 것을 흙으로 덮기

브러시 결과는 **브러시 데이터 에셋**(RSTerrainData)에 따로 저장된다.
요소를 옮겨도, 지형을 다시 만들어도 손질은 그대로 얹힌다.
크기나 격자를 바꾸면 위치 기준으로 옮겨 담는다.

## 레이어 (정점 컬러 → TerrainSplatPixelLit 셰이더)

| 채널 | 레이어 |
|---|---|
| 0 (검정) | 바탕 — 윗면 흙 / 가파른 면 절벽 (셰이더가 법선으로) |
| R | 길 |
| G | 콘크리트 |
| B | 고물 |
| A | 진흙 · 기름 |

경계 모양은 세 단계로 조절한다.
1. 지형 `경계 휘기` — 큰 굴곡
2. 지형 `경계 전이 폭` — 톱니가 파고들 여지
3. 머티리얼 `경계 흐트러짐 · 노이즈 크기 · 낱알` — 텍셀 단위 톱니 (실시간)

## 메시

- 씬에 저장하지 않는다 (DontSave). 씬을 열거나 플레이할 때 요소 + 브러시 데이터로 다시 만든다 → 씬 파일이 가볍다
- 20 유닛 조각(chunk)으로 나뉘어, 브러시는 닿은 조각만 다시 만든다
- 폐자재는 머티리얼별로 메시 하나로 합쳐진다. 브러시 스트로크가 끝나면 고친 지면에 다시 앉는다
- 정점을 직접 편집하고 싶으면 **ProBuilder 로 변환** (복사본 생성, 원본은 꺼 둠)

## 파일

```
RSTerrain/
  RSTerrain.Runtime.asmdef
  RSTerrain.cs            지형 컴포넌트 (생성 · 브러시 · 조회)
  RSTerrainFeatures.cs    요소 공통 기반 (RSTerrainFeature)
  RSPlateau / RSHeap / RSPit / RSPad / RSSpline / RSScatter.cs
                          요소 하나당 파일 하나 (파일 이름 = 클래스 이름 — 안 지키면 씬에서 스크립트가 끊긴다)
  RSTerrainData.cs        브러시 데이터 에셋
  RSTerrainCore.cs        레이어 · 노이즈 · 도형 거리
  RSTerrainScatter.cs     폐자재 조각 · 메시 합치기
  Editor/
    RSTerrain.Editor.asmdef
    RSTerrainEditor.cs    인스펙터 · 브러시 · 자동 갱신 · 메뉴 · ProBuilder 변환
    RSFeatureEditor.cs    요소 씬 핸들
    RSTerrainExamples.cs  예제 폐철장
셰이더: RSBillboard/TerrainSplatPixelLit.shader
```
