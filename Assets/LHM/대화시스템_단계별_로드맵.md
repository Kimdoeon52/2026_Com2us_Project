# 리얼스틸 대화 시스템 — 단계별 구현 로드맵

> 엔진: Unity 6 / C#
> 진행 원칙: **작게 만들고 → Play로 확인 → "다음"이라고 하면 다음 단계**
> 한 단계 = 새 스크립트 1개(30~80줄) + 눈으로 확인할 수 있는 완료 조건
> 개정: 2026-10-29 v8 — 기획서 v1000.5(길드 토벌·시즌 랭킹 개편, 보안·안정성 설계) 반영 (8장)
> 개정: 2026-10-31 v9 — 8-1·8-2·9·10단계 완료, 11단계 작성, 씬 자동 배치 메뉴 도입 (8장)
> 단계별 설명: `대화시스템_구현가이드_R단계.md`, `대화시스템_구현가이드_9-11단계.md`

---

## 1. 왜 단계별로 다시 하는가

처음에는 완성본 패키지(Core + Runtime + Editor, 약 40개 파일)를 한 번에 설계하고 Unity에 연결만 하는 방식으로 진행했다.
연결 작업 중 다음 문제가 드러났다.

- 무엇이 왜 필요한지 체감하기 어려움
- 연결이 덜 된 컴포넌트가 Play 시 에러를 냄
- 문제가 생겼을 때 원인을 좁히기 어려움
- 1차 설계가 기획서(PDF)를 검토하지 않고 진행됨 → 기획서와 어긋나는 부분 발생

---

## 2. 코드 작성 방침 — 전부 새로 작성 (확정)

- 1차 설계 패키지는 프로젝트에서 모두 삭제했다 (2026-10-13)
- 규칙 코드(조건 선택, 소비 규칙, 세이브, 검증)까지 모든 스크립트를 단계마다 새로 작성한다
- 스크립트 설명은 `대화시스템_구현가이드.md`에 작성하고, `.cs` 파일에는 주석을 넣지 않는다

## 6. 입력 처리 전략

- **1~9단계**: 키보드를 직접 읽는 임시 코드
- **10단계**: `.inputactions`의 **Field / Battle / Dialogue** 맵 전환으로 교체

| 맵 | 키 |
|---|---|
| Field | WASD / 방향키 4방향 이동, E 상호작용 |
| Battle | ←/→ 이동, ↑ 점프, Space 회피, D 기본기, Q/W/E/R 파츠 스킬 |
| Dialogue | Space / Enter / 좌클릭 확인, Esc 스킵, Ctrl(홀드) 빨리감기, Tab 오토, L 백로그 (휠업 금지) |

## 7. 단계 진행 규칙

1. 단계 시작 시: 만들 것, 새 스크립트, 연결할 오브젝트 안내
2. 작성 → 인스펙터 연결 → Play
3. 완료 조건 확인 후 스크린샷 또는 결과 공유
4. 문제는 그 단계 안에서 해결
5. 사용자가 **"다음"**이라고 하면 다음 단계로
